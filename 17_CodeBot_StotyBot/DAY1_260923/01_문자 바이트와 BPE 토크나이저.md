# 01. 문자 바이트와 BPE 토크나이저

[← DAY1 목차](<README.md>) · [원본 노트북](<01_문자 바이트와 BPE 토크나이저.ipynb>)

문자를 숫자로 바꾸는 가장 단순한 방법부터 시작해 BPE 토크나이저를 직접 만들었다. 뒤의 CodeBot과 StoryBot이 사용하는 토큰 ID의 출발점이다.

## 핵심 개념

문자 단위 토크나이저는 Unicode 코드 포인트를 사용하고, 바이트 단위 토크나이저는 UTF-8로 인코딩한 0~255의 값을 사용한다. 한글과 이모지는 하나의 문자라도 여러 바이트가 되므로 문자 수와 바이트 수는 다르다.

BPE는 자주 함께 나오는 두 토큰을 하나로 합치는 일을 반복한다. merge rule의 순서가 인코딩 결과를 결정하고, 디코딩은 합쳐진 토큰을 바이트로 풀어 원문을 복원한다.

## 실습 흐름

문자·바이트 인코딩을 비교하고 인접 쌍 세기, 쌍 병합, 반복 학습 함수를 구현했다. 이후 종료 토큰과 정규식 기반 사전 분리를 추가해 단순한 전체 문자열 병합에서 실제 토크나이저에 가까운 구조로 확장했다.

## 실행 결과

저장된 예제에서는 한글과 이모지가 포함된 문장을 encode한 뒤 원문으로 복원했다. 마지막 예제의 “Say hello!”는 세 개의 토큰으로 표현된다. 이 숫자는 해당 예제의 학습 문장과 작은 어휘에 대한 결과다.

## 필요한 파일

텍스트는 코드 안에 있어 별도 말뭉치 파일이 필요 없다. 첫 셀은 CUDA 사용을 확인하는 assert가 있으므로 해당 GPU 커널을 선택해야 한다.

## 다시 볼 것

학습과 추론에서 같은 merge rule과 종료 토큰 ID를 사용한다. 압축률만 높이는 것보다 토큰 경계와 원문 복원이 일관적인지 먼저 확인한다.
