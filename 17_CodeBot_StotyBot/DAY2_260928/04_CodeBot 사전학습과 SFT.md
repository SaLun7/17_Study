# 04. CodeBot 사전학습과 SFT

[← DAY2 목차](<README.md>) · [원본 노트북](<04_CodeBot 사전학습과 SFT.ipynb>)

코드 말뭉치로 다음 토큰 예측을 학습하고, 지시문·응답 데이터로 SFT를 진행했다. 토큰화부터 간단한 대화 입력까지 이어지는 파일이다.

## 핵심 개념

사전학습은 문장의 앞부분으로 다음 토큰을 맞히는 과정이다. 입력 시퀀스와 정답 시퀀스는 한 토큰씩 어긋난다. SFT는 지시문과 답변 형식의 예제를 사용해 응답하는 방식을 추가로 학습한다.

SFT에서는 prompt와 response를 연결하되 어느 구간에 손실을 적용하는지 확인해야 한다. Padding이나 지시문까지 무조건 정답으로 학습하는 경우와 응답 부분을 중심으로 학습하는 경우는 목적이 다르다.

## 실습 흐름

BPE 압축 정도를 확인하고 텍스트를 uint16 토큰 바이너리로 바꾼다. TokenDataset과 GPT를 구성해 사전학습하거나 기존 가중치를 불러온다. 이어 instruction·response JSON으로 SFT를 진행한 뒤 생성 결과를 확인한다.

## 실행 결과

저장본의 모델 크기는 11,121,640개 파라미터다. 사전학습은 기존 체크포인트를 읽어 생략했고 SFT는 500회 진행한 기록이 있다. 마지막 손실 약 0.0723은 해당 학습 배치의 값이지 정답 코드 생성률이 아니다. 생성 예시에는 문법과 내용이 어색한 코드도 남아 있다.

## 필요한 파일

CodeBot 폴더의 `tiny_codes.txt`, `tiny_codes_sft.json`, `merge_rules.pkl`, `model.py`, `tokenizer.py`, `utils.py`를 사용한다. DAY2에는 기존 `.pt` 두 개와 토큰 `.bin`도 이미 Git에 포함돼 있다. 새로 생성되는 가중치·바이너리는 ignore 대상이다.

## 다시 볼 것

마지막 대화 셀은 입력을 계속 받는 반복문이므로 종료할 때 셀을 중단한다. 생성 코드는 실행 전에 내용을 검토해야 하며 손실 감소만으로 코드의 정확성이 보장되지는 않는다.
