# 코드봇 웹서비스 요구사항 명세서

## 1. 목적

사용자가 Python 코드의 앞부분을 입력하고 버튼을 누르면, 기존 코드봇이 그 뒤를 생성하여 화면에 보여주는 최소 기능 웹서비스를 만든다. 이 문서는 서비스 구현 요구사항이며, 현재 단계의 작업 범위는 명세서 작성까지다.

## 2. 기존 코드와 확정된 설정

| 항목 | 요구사항 및 근거 |
| --- | --- |
| 백엔드 | FastAPI |
| 프론트엔드 | React |
| 모델 | 기존 `model_pretrain.pt` 사용. `04.ipynb`에서 코드 앞부분을 직접 이어 생성하는 예시에 쓰인 모델이다. |
| 토크나이저 | 기존 `merge_rules.pkl`을 `tokenizer.py`의 `BPETokenizer.load_from()`으로 읽는다. |
| 모델 로드 | 기존 `model.py`의 `GPT.load_from()`을 사용한다. |
| 코드 생성 | 기존 `utils.py`의 `generate()`를 사용한다. |
| 모델 문맥 길이 | 256토큰. `04.ipynb`의 학습 설정은 `context_len = 256`이며 모델에도 `max_context_len`이 저장된다. 실행 시 로드한 모델의 `max_context_len`이 256인지 확인한다. |
| 사용자 입력 한도 | 기존 토크나이저로 인코딩한 결과가 **최대 56토큰**이어야 한다. |
| 생성 한도 | 한 요청에서 `max_new_tokens=200`을 사용한다. |
| 생성 설정 | 기존 코드 예시와 같이 `temperature=1.0`을 사용한다. |
| 결과 표시 | 사용자 입력 앞부분과 생성된 뒷부분을 합친 **전체 코드**를 표시한다. |

입력 56토큰과 생성 200토큰의 합은 모델 문맥 길이 256토큰이다. `utils.py`의 기본 생성 한도는 1000토큰이므로 웹서비스에서는 반드시 200을 명시한다. 입력 제한을 글자 수나 UTF-8 바이트 수로 대체하지 않는다.

## 3. 사용자 기능

1. 누구나 로그인 없이 페이지에 접속할 수 있다.
2. 화면에는 코드 입력창, 생성 버튼, 결과 표시 영역만 둔다. 입력과 결과의 줄바꿈 및 들여쓰기를 보존한다.
3. 사용자가 코드 앞부분을 입력하고 생성 버튼을 누르면 프론트엔드가 이를 FastAPI 백엔드에 보낸다.
4. 백엔드는 입력을 기존 `BPETokenizer.encode()`로 토큰화한다. 비어 있거나 공백뿐인 입력 및 56토큰 초과 입력은 생성하지 않고 이유를 반환한다. 토큰 한도는 서버에서 최종 검증한다.
5. 유효한 입력이면 백엔드는 기존 모델과 생성 함수를 사용해 코드의 뒷부분을 최대 200토큰 생성한다. 입력 앞에 명령문 템플릿을 붙이지 않는다.
6. 프론트엔드는 반환된 전체 코드를 결과 영역에 표시한다. 입력 한도 초과 또는 생성 실패 시에는 결과 대신 이해할 수 있는 오류 메시지를 표시한다.
7. 요청 처리 중에는 생성 버튼을 중복으로 누르지 못하게 한다.

## 4. 연동 및 실행 요구사항

- FastAPI는 서버 시작 시 `model_pretrain.pt`와 `merge_rules.pkl`을 읽어 추론에 사용한다. 요청마다 모델을 다시 로드하지 않는다.
- 프론트엔드는 코드 앞부분을 한 번의 생성 요청으로 보낸다. 백엔드는 성공 시 전체 코드 문자열을 반환한다.
- `generate()`가 입력과 생성 결과를 합친 문자열을 반환하므로, 화면에 표시할 전체 코드는 그 반환값을 사용한다.
- 모델 추론을 위해 서버에 PyTorch, 토크나이저 실행을 위해 `regex` 등 기존 코드의 의존성이 필요하다. 현재 확인한 Python 환경에는 `torch`가 설치되어 있지 않아 이 환경에서 실제 추론은 검증하지 못했다.
- 모델 또는 토크나이저 파일을 읽을 수 없거나 모델의 문맥 길이가 예상과 다르면, 서비스가 정상적으로 준비되지 않았음을 서버에서 드러내야 한다.

## 5. 최소 완료 기준

- 로그인 없이 React 화면을 열 수 있다.
- `def` 같은 유효한 코드 앞부분을 입력하고 버튼을 누르면, 기존 `model_pretrain.pt`가 생성한 내용을 포함한 전체 코드가 화면에 나타난다.
- 기존 토크나이저 기준 정확히 56토큰인 입력은 허용하고 57토큰인 입력은 거부한다.
- 빈 입력과 공백뿐인 입력은 거부한다.
- 생성 요청의 `max_new_tokens`는 200이며 모델 입력 한도를 넘는 요청은 추론 전에 거부된다.
- 오류가 발생해도 페이지가 멈추지 않고 사용자에게 오류 메시지가 보인다.

## 6. 범위 제외

회원가입·로그인, 사용 기록 저장, 코드 실행, 파일 업로드, 모델 재학습, 여러 모델 선택, 추가 챗봇 기능은 이번 최소 기능에 포함하지 않는다.
