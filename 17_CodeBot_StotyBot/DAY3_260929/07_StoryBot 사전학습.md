# 07. StoryBot 사전학습

[← DAY3 목차](<README.md>) · [원본 노트북](<07_StoryBot 사전학습.ipynb>)

TinyStories 말뭉치로 짧은 이야기를 이어 쓰는 언어 모델을 학습했다. 학습 손실과 별도의 검증 손실을 함께 기록하는 단계다.

## 핵심 개념

긴 말뭉치를 토큰 ID 바이너리로 저장하고 일정한 context 길이의 구간을 잘라 입력으로 만든다. 정답은 같은 구간을 한 칸 뒤로 옮긴 시퀀스다. 검증에서는 전체 토큰 수로 손실을 평균내어 배치 크기가 다른 마지막 구간도 반영한다.

Warmup은 학습 초기에 학습률을 서서히 높이는 과정이다. 이후 학습률을 낮추면서 갱신 크기를 줄인다. 혼합 정밀도와 바이너리 데이터 처리는 계산·메모리 부담을 줄이는 데 사용된다.

## 실습 흐름

BPE 규칙을 학습하고 train·valid 텍스트를 토큰 바이너리로 바꾼다. GPT와 optimizer를 구성한 뒤 주기적으로 검증하고 중간 체크포인트와 마지막 모델을 저장한다.

## 실행 결과

저장된 모델은 약 2,270만 파라미터이고 10,000회 학습 기록이 있다. 마지막 검증 손실은 약 1.4714다. 이는 다음 토큰 예측 손실이며 이야기의 문법·일관성에 대한 별도 평가 점수는 아니다.

## 필요한 파일

`storybot/tiny_stories_train.txt`, `storybot/tiny_stories_valid.txt`는 저장소에 없어 별도 준비가 필요하다. `model.py`, `tokenizer.py`, `utils.py`, `merge_rules.pkl`은 포함돼 있다. 바이너리와 가중치는 실행 중 생성한다.

## 다시 볼 것

모델과 토크나이저의 어휘 크기를 맞추고 train·valid 데이터가 섞이지 않게 한다. 웹서비스는 이 모델을 사용하므로 학습 파일의 위치를 바꾸면 서비스 설정도 같이 확인한다.
