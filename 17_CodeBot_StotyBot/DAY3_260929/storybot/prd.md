# 스토리봇 웹서비스 PRD

## 제품 목표

기존 Python 스토리봇이 영어 이야기의 첫 문장을 이어 쓰도록 하고, 회원이 생성한 이야기를 저장·공유·관리할 수 있는 별도 웹서비스를 만든다. 코드봇 서비스와 통합하지 않는다.

## 사용자와 핵심 흐름

- 비회원: 메인 페이지와 공개 스토리 목록·상세 내용을 볼 수 있다.
- 회원: 가입·로그인 후 영어 첫 문장을 입력하여 이야기를 생성한다. 완료된 이야기는 자동 저장되며 생성 시 공개 또는 비공개를 선택한다.
- 회원: 내 스토리 목록에서 자신의 공개·비공개 이야기를 확인하고 제목·본문·공개 상태를 수정하거나 삭제한다.
- 회원: 공개 스토리에 좋아요를 누르고 같은 버튼으로 취소한다. 자신의 공개 스토리도 좋아요를 누를 수 있다.
- 회원: 이메일·닉네임·비밀번호를 변경하고 로그아웃하거나 탈퇴할 수 있다.

## 기능 요구사항

| ID | 요구사항 |
| --- | --- |
| AUTH-01 | 이메일·비밀번호·닉네임으로 가입한다. 이메일은 중복 가입할 수 없다. |
| AUTH-02 | 로그인 시 서버에 저장하는 세션 토큰을 발급하여 HttpOnly 쿠키로 전달한다. 로그아웃 시 서버의 토큰을 무효화한다. |
| AUTH-03 | 로그인한 회원은 본인의 이메일·닉네임·비밀번호를 수정할 수 있다. 비밀번호 변경 및 탈퇴에는 현재 비밀번호 확인이 필요하다. |
| AUTH-04 | 탈퇴 시 회원, 해당 회원의 스토리, 좋아요 및 세션을 영구 삭제한다. |
| STORY-01 | 로그인한 회원만 스토리를 생성할 수 있다. 사용자는 영어 이야기의 첫 문장과 공개 여부를 입력한다. |
| STORY-02 | 생성 성공 시 입력 문장과 모델이 이어 쓴 결과를 한 편의 스토리로 자동 저장한다. 제목은 완성된 스토리의 첫 문장에서 자동으로 만든다. |
| STORY-03 | 공개 스토리는 모두 열람할 수 있다. 비공개 스토리는 작성자만 열람할 수 있다. |
| STORY-04 | 내 스토리 목록에는 작성자의 공개·비공개 스토리를 모두 표시한다. |
| STORY-05 | 작성자만 자신의 스토리 제목·본문·공개 여부를 수정하거나 삭제할 수 있다. |
| LIKE-01 | 로그인한 회원은 공개 스토리에 좋아요를 한 번 누를 수 있고, 다시 누르면 취소된다. 본인 스토리도 허용한다. |
| LIKE-02 | 공개 스토리 목록과 상세 화면에 좋아요 수 및 로그인한 회원의 좋아요 여부를 표시한다. 비공개 스토리에는 좋아요를 누를 수 없다. |
| UI-01 | 메인 화면은 따뜻한 동화책 분위기로 구성한다. 공개 이야기, 내 이야기, 생성, 계정으로 이동할 수 있다. |
| UI-02 | 생성 중 중복 요청을 막고, 입력 오류·인증 실패·서버 오류를 사용자에게 알린다. |

## 기존 모델 사용과 입력 한도

- `storybot/model_pretrain.pt`, `merge_rules.pkl`, `model.py`, `tokenizer.py`, `utils.py`를 그대로 서비스의 추론 경로에 사용한다. 다른 생성 모델이나 외부 AI API를 사용하지 않는다.
- 학습 노트북 `01.ipynb`의 문맥 길이는 256토큰이다. 서버는 로드된 모델의 `max_context_len`을 확인한다.
- 입력 문장은 기존 `BPETokenizer.encode()` 기준 최대 56토큰이다. 생성 시 기존 `utils.generate()`에 `max_new_tokens=200`을 명시하여 입력과 생성 한도의 합을 256토큰 이하로 유지한다.
- 공백 입력과 토큰 한도 초과 입력은 추론 전에 거부한다. 서버가 토큰 수를 최종 판정한다.
- 기존 토크나이저의 종료 토큰이 생성되면 이야기는 200토큰보다 일찍 끝날 수 있다.
- 학습 데이터는 영어 동화이므로 첫 버전의 입력과 생성 결과는 영어 이야기로 안내한다. 완성된 이야기의 품질이나 길이는 모델 출력에 따른다.

## 기술 구성 및 데이터

- 스토리봇 전용 React 프론트엔드, FastAPI 백엔드, SQLite 데이터베이스를 사용한다.
- 회원 비밀번호는 평문으로 저장하지 않고 단방향 해시로 저장한다. 세션 토큰도 원문 대신 해시를 데이터베이스에 저장한다.
- 서버는 회원, 세션, 스토리, 좋아요를 저장한다. 스토리는 작성자, 제목, 본문, 공개 여부, 생성·수정 시각을 가진다. 좋아요는 회원과 공개 스토리의 조합당 하나만 저장한다.
- 인증 쿠키는 HttpOnly·SameSite 설정을 사용하고, 운영 환경에서는 HTTPS와 Secure 쿠키를 사용한다.
- 쿠키는 브라우저 세션 동안 유지한다. 서버에 저장한 토큰은 안전을 위해 최대 30일 후 만료한다.
- 비공개 스토리 및 회원 정보 접근 권한은 화면 숨김에 의존하지 않고 API에서 검증한다.

## 완료 기준

1. 비회원이 공개 스토리를 열람하고, 회원 전용 동작에는 로그인이 요구된다.
2. 가입·로그인·로그아웃·정보 변경·비밀번호 변경·탈퇴가 동작하며 로그아웃 후 기존 세션으로 요청할 수 없다.
3. 유효한 영어 첫 문장으로 기존 스토리봇이 만든 결과가 자동 저장되고 내 스토리에서 확인된다.
4. 56토큰 입력은 허용하고 57토큰 입력은 모델 호출 전에 거부한다.
5. 공개·비공개 접근 제어, 작성자만 수정·삭제, 좋아요 추가·취소가 동작한다.
6. 탈퇴 시 해당 회원의 스토리와 좋아요가 더 이상 조회되지 않는다.

## 이번 버전의 범위 밖

코드봇 통합, 한국어 번역, 이미지 생성, 댓글, 팔로우, 검색, 관리자 화면, 소셜 로그인, 이메일 인증, 외부 배포는 포함하지 않는다.
