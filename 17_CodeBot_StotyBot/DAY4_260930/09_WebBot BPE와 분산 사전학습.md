# 09. WebBot BPE와 분산 사전학습

[← DAY4 목차](<README.md>) · [원본 노트북](<09_WebBot BPE와 분산 사전학습.ipynb>)

웹 텍스트 말뭉치를 사용하는 언어 모델 학습 예제다. 큰 어휘의 BPE와 분산 학습, 학습 기록 수집을 다룬다.

## 핵심 개념

텍스트를 BPE 토큰 바이너리로 바꾼 뒤 일정 길이의 구간으로 학습한다. 데이터가 커지면 토크나이저 학습과 인코딩 시간도 무시하기 어렵다. 코드에는 파일 일부로 BPE를 학습하는 주석 예제도 함께 있다.

DDP는 여러 프로세스가 모델 복제본을 학습하고 기울기를 동기화하는 방식이다. 프로세스 수, 장치 배치, 실행 방식이 맞아야 하며 노트북에서 셀을 실행하는 것만으로 분산 환경이 준비되는 것은 아니다.

## 실습 흐름

OpenWebText train 파일로 어휘 크기 50,000의 BPE를 학습한다. train·valid 바이너리를 만들고 GPT, 학습률 스케줄, 평가 함수, 학습 루프와 생성 함수를 구성한다. 모델 모듈에는 RoPE, GQA, RMSNorm과 SwiGLU가 들어 있다.

## 실행 결과

저장본은 BPE 병합 과정의 약 42%에서 `KeyboardInterrupt`로 중단됐다. 뒤의 사전학습과 생성에는 완료 출력이 없으므로 완성된 WebBot 모델이 제공되는 상태로 보지 않는다.

## 필요한 파일

DAY4의 `webbot/owt_train.txt`, `webbot/owt_valid.txt`를 별도로 준비해야 한다. `model.py`, `utils.py`는 실제 import 경로에 맞춰 `webbot/`으로 모았다. 토크나이저 코드는 DAY3 StoryBot 모듈을 공유한다. 바이너리, 병합 규칙과 가중치는 해당 데이터로 만든다.

## 다시 볼 것

이 실습은 데이터 크기와 분산 설정을 확인한 뒤 실행한다. 학습 루프의 W&B 사용 설정도 확인하고, 토크나이저 학습이 끝나지 않은 상태에서 다음 단계로 넘어가지 않는다.
