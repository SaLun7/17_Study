# 12. 규칙 기반 리뷰 감정 분석

[← DAY6 목차](<README.md>) · [원본 노트북](<12_규칙 기반 리뷰 감정 분석.ipynb>)

리뷰에 포함된 긍정·부정 단어를 세어 감정과 처리 우선순위를 정하는 예제다. 학습 모델을 사용하기 전에 입력부터 업무 처리까지의 흐름을 확인한다.

## 핵심 개념

텍스트 전처리와 모델 추론을 보여주는 첫 함수는 중간값과 예측값을 직접 적어 둔 설명용 코드다. 뒤의 분석기도 학습된 신경망이 아니라 키워드 포함 여부를 확인하는 규칙 기반 방식이다.

긍정 키워드가 많으면 긍정, 부정 키워드가 많으면 부정, 수가 같으면 중립으로 분류한다. `confidence`는 키워드 개수로 계산한 임의 점수이며 통계적으로 검증된 확률이 아니다.

## 실습 흐름

리뷰를 하나씩 분석해 감정, 점수, 담당 업무, 우선순위를 출력한다. `Counter`로 감정과 업무별 개수를 집계한 뒤, 순차적으로 들어오는 리뷰를 처리하는 모니터링 예제로 이어진다.

## 실행 결과

저장된 실행 출력은 없다. 코드를 보면 키워드 목록에 없는 불만 표현은 부정으로 잡지 못할 수 있다. “좋지 않다”처럼 부정 표현이 붙어도 `좋`을 포함했다는 이유로 긍정 점수가 올라가는 한계가 있다.

## 필요한 파일

별도 파일 없이 코드 안의 리뷰 목록을 사용한다. 스트리밍 예제도 외부 서비스가 아니라 리스트의 문장을 차례로 처리한다.

## 다시 볼 것

규칙 기반 결과를 학습 모델의 정확도나 신뢰도로 소개하지 않는다. 오분류 사례를 모은 뒤 어떤 전처리와 문맥 모델이 필요한지 생각해 보는 출발점으로 사용한다.
