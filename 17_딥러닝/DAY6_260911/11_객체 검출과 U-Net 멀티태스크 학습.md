# 11. 객체 검출과 U-Net 멀티태스크 학습

[← DAY6 목차](<README.md>) · [원본 노트북](<11_객체 검출과 U-Net 멀티태스크 학습.ipynb>)

객체의 위치를 표현하는 bounding box부터 U-Net, 추론 시 데이터 증강, 분류와 세그멘테이션을 함께 학습하는 구조까지 정리한 예제다.

## 핵심 개념

객체 검출의 box 회귀는 기준 상자인 anchor와 정답 상자의 차이를 학습한다. 중심 좌표의 이동과 폭·높이의 비율을 encode하고, 예측한 offset을 decode해 원래 좌표로 되돌린다.

U-Net은 해상도를 줄인 특징과 대응하는 고해상도 특징을 skip connection으로 이어 픽셀별 예측을 만든다. Dice loss는 예측 영역과 정답 영역의 겹침을 기준으로 손실을 계산한다. 멀티태스크 모델은 특징 추출부를 공유하고 분류 head와 세그멘테이션 head를 따로 둔다.

검출은 객체마다 상자를 만들고 세그멘테이션은 픽셀마다 라벨을 만든다. 둘 다 위치를 다루지만 정답 자료와 출력 형태가 다르다. 공유 특징이 한 과제에는 도움이 되고 다른 과제에는 방해가 될 수도 있으므로, 합산 손실만 보지 말고 분류와 분할의 손실·평가값을 각각 기록하는 편이 좋다.

## 실습 흐름

anchor 생성과 box 변환 함수를 정의한 뒤 U-Net의 down·up 블록과 Dice loss를 구현했다. 뒤집기·크기 변경을 사용하는 TTA, 여러 모델의 출력을 합치는 앙상블, 두 과제의 손실을 고정 비중 또는 학습 가능한 불확실성 가중치로 합치는 예제로 이어진다.

## 실행 결과

현재 저장본에는 실행 출력이 없다. 테스트용 입력과 학습 함수 정의가 있어도 실제 검출·분할 성능이 검증된 상태는 아니다. `MultiTaskDataset`도 실제 라벨 이미지가 아니라 임의 데이터를 만드는 구성 예제다.

## 필요한 파일

예제의 입력은 코드에서 생성하므로 외부 이미지 데이터가 필수는 아니다. 실제 데이터셋으로 성능을 확인하려면 분류 라벨과 픽셀 마스크를 함께 준비해야 한다.

## 다시 볼 것

TTA로 뒤집은 분할 결과는 원래 좌표로 복원한 뒤 합쳐야 한다. 두 과제의 손실값 규모가 다르면 단순 합산에서 한쪽이 학습을 지배할 수 있으므로 가중치를 함께 본다.
