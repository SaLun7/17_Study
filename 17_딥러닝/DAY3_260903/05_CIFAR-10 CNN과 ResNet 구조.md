# 05. CIFAR-10 CNN과 ResNet 구조

[← DAY3 목차](<README.md>) · [원본 노트북](<05_CIFAR-10 CNN과 ResNet 구조.ipynb>)

CIFAR-10용 CNN에서 시작해 입력을 출력에 더하는 잔차 연결을 구현하고, 이를 여러 층으로 쌓은 ResNet 구조까지 확장했다.

## 배운 내용

- 합성곱의 패딩과 스트라이드에 따른 특징맵 크기를 다시 확인했다.
- 배치 정규화와 드롭아웃을 포함한 기본 CNN을 구성했다.
- ResidualBlock에서 합성곱 결과와 입력을 더하는 skip connection을 구현했다.
- 채널 수나 해상도가 달라질 때 shortcut 경로를 맞추는 방법을 살펴봤다.
- BasicBlock을 반복해 ResNet 형태의 모델을 만들었다.
- 학습률 스케줄러와 여러 가중치 초기화 방법을 비교했다.

## 핵심 개념

깊은 모델은 단순히 층을 많이 쌓는다고 항상 좋아지지 않는다. 잔차 연결은 블록이 완전히 새로운 출력을 만드는 대신 입력에서 필요한 변화만 학습하게 한다. 기울기가 shortcut을 통해 전달될 수 있어 깊은 네트워크의 학습을 돕는다.

입력과 블록 출력의 shape이 같아야 두 값을 더할 수 있다. 해상도를 줄이거나 채널을 늘리는 블록에서는 1×1 합성곱 같은 projection shortcut으로 크기를 맞춘다.

## 실습 흐름

기본 CNN과 CIFAR-10 데이터 준비를 확인한 뒤 ResidualBlock 하나를 만들었다. 이어서 블록을 단계별로 쌓아 전체 ResNet을 구성하고 임의 입력을 넣어 각 출력 shape을 점검했다. 마지막에는 학습률을 줄이는 방식과 초기화 방법을 작은 예제로 살펴봤다.

## 실행 결과

구성한 ResNet의 파라미터는 약 1,117만 개이며 임의 입력에 대해 10개 클래스 출력이 만들어졌다. 구조 구현 중심의 노트북이라 최종 분류 정확도는 따로 기록하지 않았다.

## 다시 볼 것

- 잔차를 더하기 전에 입력과 출력 shape이 같은지 확인한다.
- 스케줄러마다 `step()`을 호출하는 시점과 인자가 다르다.
- 모델 크기뿐 아니라 학습 시간과 테스트 성능을 함께 비교한다.
