# 06. 안전모 착용 분류와 전이학습

[← DAY3 목차](<README.md>) · [원본 노트북](<06_안전모 착용 분류와 전이학습.ipynb>)

안전모 이미지와 XML 어노테이션으로 착용 여부를 나누고 직접 만든 CNN과 전이학습 모델을 비교했다.

## 실습 내용

- XML에서 파일명과 객체 정보를 읽어 안전·위험 라벨을 만들었다.
- 5,000장 데이터를 훈련·검증·테스트로 나눴다.
- 기본 CNN과 EfficientNetV2-S 전이학습 모델을 비교했다.
- 클래스 불균형을 확인하고 손실 함수에 가중치를 적용했다.

## 실행 결과

2회 학습 기준 테스트 AUC는 기본 CNN 약 0.6122, 전이학습 약 0.7788, 클래스 가중치 적용 모델 약 0.8045였다. 실행 횟수가 짧아 수치 자체보다 전이학습과 불균형 처리에 따른 변화를 확인하는 실습에 가깝다.
