# 06. 안전모 착용 분류와 전이학습

[← DAY3 목차](<README.md>) · [원본 노트북](<06_안전모 착용 분류와 전이학습.ipynb>)

안전모 이미지와 XML 어노테이션에서 착용 여부를 만들고, 직접 만든 CNN과 ImageNet 사전학습 모델의 차이를 비교했다.

## 데이터 준비

`helmet/images`에는 원본 이미지가, `helmet/annotations`에는 같은 이미지의 객체 정보가 담긴 XML 파일이 들어간다. XML에서 파일명과 객체 이름을 읽어 안전모 착용 여부를 라벨로 만들었다. 읽지 못한 이미지가 섞이지 않도록 파일 존재 여부도 함께 확인한다.

전체 5,000장 이미지는 클래스 비율을 유지하면서 훈련·검증·테스트로 나눴다. 모델이 이미지를 쉽게 처리하도록 224×224 크기로 맞추고, 전이학습 모델에는 ImageNet 기준 정규화를 적용했다.

## 핵심 개념

직접 만든 CNN은 모든 특징을 현재 데이터만 보고 처음부터 배운다. 전이학습은 대규모 ImageNet에서 학습된 EfficientNetV2-S의 특징 추출 능력을 가져와 마지막 분류 부분을 현재 문제에 맞춘다. 데이터가 많지 않을 때 학습을 빠르게 안정시키는 데 유리하다.

두 클래스의 수가 다르면 많은 클래스 쪽으로 예측이 기울 수 있다. 이 노트에서는 클래스 개수로 가중치를 계산해 손실 함수에 적용하고, 단순 정확도보다 AUC와 혼동행렬을 함께 확인했다.

## 실습 흐름

XML과 이미지를 읽어 배열을 만든 뒤 데이터를 세 부분으로 나눴다. 기본 CNN을 기준선으로 학습하고, EfficientNetV2-S의 특징 추출부를 고정한 전이학습 모델을 같은 조건에서 비교했다. 마지막에는 클래스 가중치를 적용해 소수 클래스 예측이 달라지는지 확인했다.

## 실행 결과

2 epoch 기준 테스트 AUC는 기본 CNN 약 0.6122, 전이학습 약 0.7788, 클래스 가중치 적용 모델 약 0.8045였다. 학습 횟수가 짧으므로 최종 성능이라기보다 전이학습과 불균형 처리가 어느 방향으로 영향을 주는지 확인한 결과에 가깝다.

## 다시 볼 것

- 데이터 분할 전에 중복 이미지나 같은 장면이 섞였는지 확인한다.
- 클래스 가중치는 정확도보다 정밀도와 재현율의 균형에 영향을 줄 수 있다.
- 저장된 체크포인트와 같은 모델 구조·정규화 방식을 사용해야 한다.
