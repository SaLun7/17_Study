# 07. 흉부 X-ray 폐렴 분류

[← DAY3 목차](<README.md>) · [원본 노트북](<07_흉부 X-ray 폐렴 분류.ipynb>)

흉부 X-ray를 정상과 폐렴으로 분류하고, 의료 분류에서 중요한 오류의 종류와 판정 임계값을 함께 살펴봤다.

## 데이터와 모델

`chest_xray/train`과 `test` 아래의 `NORMAL`, `PNEUMONIA` 폴더를 ImageFolder로 읽었다. 훈련 폴더 일부는 검증용으로 분리하고, 영상은 224×224로 맞춘 뒤 ImageNet 평균과 표준편차로 정규화했다.

모델은 timm의 ResNetV2-50 사전학습 가중치를 이용하고 마지막 층을 정상·폐렴 이진 분류에 맞췄다. 출력 logit은 Sigmoid를 거쳐 폐렴일 확률로 해석했다.

## 핵심 개념

민감도는 실제 폐렴 가운데 모델이 찾아낸 비율이고, 특이도는 실제 정상 가운데 정상으로 판정한 비율이다. 의료 선별 문제에서는 폐렴을 정상으로 놓치는 false negative의 비용이 클 수 있어 정확도 하나로 모델을 판단하기 어렵다.

기본 임계값 0.5를 낮추면 더 많은 영상을 폐렴으로 판단해 민감도는 올라가지만 정상 영상을 폐렴으로 보는 경우도 늘 수 있다. ROC-AUC와 PR-AUC는 특정 임계값 하나에 묶이지 않고 예측 순위를 비교하는 지표다.

## 실습 흐름

데이터 분포와 샘플 영상을 확인한 뒤 모델을 학습하고 가장 좋은 검증 체크포인트를 저장했다. 테스트 데이터에서 혼동행렬과 여러 지표를 계산하고, 임계값을 바꾸며 false negative 수를 비교했다. 마지막에는 Grad-CAM으로 분류에 영향을 준 영상 영역을 표시했다.

## 실행 결과

저장된 결과는 정확도 약 89.22%, 민감도 97.99%, 특이도 74.79%, ROC-AUC 0.9650이었다. 임계값을 0.40으로 낮추면 민감도는 약 99.25%였고 놓친 폐렴 영상은 3장으로 기록됐다.

## 다시 볼 것

- 원하는 임계값은 실제 오진 비용을 기준으로 정해야 한다.
- Grad-CAM은 판단 근거를 보조하는 도구이지 모델의 의학적 타당성을 증명하지 않는다.
- 이 실습 결과를 실제 진단에 사용할 수는 없으며 외부 병원 데이터 검증이 필요하다.
