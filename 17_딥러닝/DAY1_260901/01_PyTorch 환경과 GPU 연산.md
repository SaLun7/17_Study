# 01. PyTorch 환경과 GPU 연산

[← DAY1 목차](<README.md>) · [원본 노트북](<01_PyTorch 환경과 GPU 연산.ipynb>)

PyTorch를 시작하기 전에 현재 환경이 GPU를 제대로 인식하는지 확인하고, 텐서 연산을 CPU와 GPU에서 각각 실행해 차이를 살펴봤다.

## 배운 내용

- PyTorch 버전과 CUDA 사용 가능 여부를 확인했다.
- 스칼라, 벡터, 행렬 형태의 텐서를 만들고 shape과 dtype을 살펴봤다.
- 같은 행렬 곱셈을 CPU와 GPU에서 실행해 시간을 비교했다.
- Matplotlib 그래프에서 한글 제목이 깨지지 않도록 글꼴 설정도 확인했다.

## 핵심 개념

텐서는 NumPy 배열과 비슷하지만 GPU로 옮겨 계산할 수 있고 자동 미분에도 사용할 수 있다. 모델과 입력 데이터가 서로 다른 장치에 있으면 연산할 수 없으므로 둘을 같은 `device`로 보내야 한다.

GPU는 작은 계산 하나를 빠르게 처리하는 장치라기보다 같은 형태의 계산을 대량으로 병렬 처리하는 데 강하다. 따라서 텐서 크기가 작으면 데이터를 옮기는 비용 때문에 CPU가 더 빠를 수도 있다.

## 실습 흐름

먼저 CUDA 장치 이름과 사용 가능 여부를 출력했다. 그다음 동일한 크기의 임의 행렬을 준비해 CPU에서 곱하고, 같은 행렬을 GPU로 옮겨 다시 계산했다. 마지막에는 두 실행 시간을 비교하고 간단한 그래프로 결과를 표시했다.

## 실행 결과

저장된 실행에서는 CUDA 장치가 정상적으로 인식됐다. 1,000×1,000 행렬 곱셈은 GPU가 CPU보다 약 16.7배 빠르게 측정됐다. 이 수치는 GPU 종류, 첫 실행 준비 시간, 다른 프로그램의 GPU 사용량에 따라 달라질 수 있다.

## 다시 볼 것

- 모델과 입력 텐서가 같은 장치에 있는지 확인한다.
- GPU 시간 측정은 연산 완료 시점을 맞춘 뒤 비교해야 한다.
- 속도 차이보다 먼저 출력 shape과 값이 같은지 확인한다.
