# 01. PyTorch 환경과 GPU 연산

[← DAY1 목차](<README.md>) · [원본 노트북](<01_PyTorch 환경과 GPU 연산.ipynb>)

PyTorch가 GPU를 사용할 수 있는지 확인하고 텐서와 행렬 연산을 간단히 실행했다.

## 실습 내용

- CUDA 사용 가능 여부와 실행 장치를 확인했다.
- 기본 텐서를 만들고 행렬 곱셈을 CPU와 GPU에서 각각 실행했다.
- Matplotlib에서 한글 제목이 표시되는지도 확인했다.

## 실행 결과

실행 당시 CUDA 장치가 인식됐고, 1,000×1,000 행렬 곱셈에서는 GPU가 CPU보다 약 16.7배 빠르게 측정됐다. 실행 환경과 GPU 상태에 따라 시간 차이는 달라질 수 있다.
