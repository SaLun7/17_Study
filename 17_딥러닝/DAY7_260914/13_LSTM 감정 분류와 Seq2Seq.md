# 13. LSTM 감정 분류와 Seq2Seq

[← DAY7 목차](<README.md>) · [원본 노트북](<13_LSTM 감정 분류와 Seq2Seq.ipynb>)

DAY6의 리뷰 분석 예제에 LSTM 분류와 인코더·디코더 구조를 추가했다. 문장 하나를 분류하는 문제와 문장 시퀀스를 생성하는 문제의 출력 차이를 본다.

## 핵심 개념

감정 분류기는 토큰 ID를 임베딩한 뒤 LSTM의 마지막 은닉 상태를 두 클래스의 점수로 바꾼다. Seq2Seq는 입력을 인코더 상태로 압축하고 디코더가 이전 토큰과 상태를 받아 다음 토큰을 예측한다.

Teacher forcing은 디코더의 다음 입력에 자기 예측 대신 정답 토큰을 주는 학습 방법이다. 추론할 때는 정답을 알 수 없으므로 학습 때와 입력 조건이 달라진다는 점을 함께 기억한다.

## 실습 흐름

길이가 다른 네 개의 토큰 시퀀스를 패딩해서 LSTM 분류기를 학습한다. 이어 별도의 LSTM 인코더·디코더를 만들고 무작위 토큰으로 순전파, 손실 계산, 역전파 한 단계를 확인한다.

## 실행 결과

저장된 실행 출력은 없다. 감정 분류 평가는 훈련에 사용한 네 개의 샘플을 다시 넣는 방식이고, 손실·정확도 그래프의 값은 코드에 직접 적어 둔 가상 데이터다. Seq2Seq도 실제 번역 말뭉치로 학습한 결과가 아니다.

## 필요한 파일

입력 시퀀스와 라벨을 코드에서 생성하므로 별도 데이터 파일은 없다. DAY6의 규칙 기반 분석 부분은 복습용으로 포함돼 있다.

## 다시 볼 것

패딩 토큰을 임베딩에서 0으로 처리하는 것과 LSTM 계산에서 패딩 구간을 제외하는 것은 다르다. 실제 문장 분류에서는 문장 길이 처리와 독립 평가 데이터를 추가해야 한다.
