# 14. CartPole DQN과 REINFORCE

[← DAY7 목차](<README.md>) · [원본 노트북](<14_CartPole DQN과 REINFORCE.ipynb>)

CartPole에서 막대가 넘어지지 않도록 행동을 고르는 두 가지 강화학습 예제다. 행동의 가치를 예측하는 DQN과 행동 확률을 직접 학습하는 REINFORCE를 비교한다.

## 핵심 개념

DQN은 상태를 받아 각 행동의 Q값을 출력한다. 경험을 replay buffer에 모아 무작위 배치로 학습하고, target network가 계산한 다음 상태의 가치를 현재 보상과 합쳐 학습 목표로 사용한다.

REINFORCE는 정책이 출력한 확률에서 행동을 뽑는다. 에피소드가 끝나면 할인 누적 보상을 계산하고, 좋은 보상을 얻은 행동의 로그 확률을 높이는 방향으로 정책을 갱신한다.

## 실습 흐름

DQN에서는 두 개의 Q network와 경험 버퍼를 만들고 MSE로 행동 가치를 갱신한다. 에피소드가 끝날 때 target network를 조금씩 갱신한다. 뒤의 REINFORCE 예제는 행동 로그 확률과 보상을 모아 에피소드 단위로 학습한다.

## 실행 결과

저장된 실행 출력은 없어 학습 성공 여부를 판단할 수 없다. DQN의 현재 행동 선택은 Q값의 argmax만 사용하며 별도의 epsilon 탐색이 없다. 노트북은 `reset()`이 상태만 반환하고 `step()`이 네 값을 반환하는 구형 Gym 인터페이스로 작성돼 있다.

## 필요한 파일

외부 데이터 파일은 필요 없고 `gym`의 `CartPole-v1` 환경을 사용한다. 설치된 Gym의 반환 형식이 코드와 다르면 환경 호출 부분을 맞춰야 한다.

## 다시 볼 것

한 에피소드의 점수보다 여러 에피소드의 평균 보상을 본다. 탐색 방법과 종료 조건 처리는 학습 결과에 영향을 주므로 단순한 실행 옵션으로 취급하지 않는다.
