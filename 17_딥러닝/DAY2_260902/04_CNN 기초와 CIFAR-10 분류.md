# 04. CNN 기초와 CIFAR-10 분류

[← DAY2 목차](<README.md>) · [원본 노트북](<04_CNN 기초와 CIFAR-10 분류.ipynb>)

합성곱 필터가 이미지의 지역적인 특징을 찾는 과정을 직접 확인하고, CIFAR-10 분류에 사용할 CNN 구조를 만들었다.

## 배운 내용

- Sobel 필터와 세로선 검출 필터를 이미지에 직접 적용했다.
- 패딩과 스트라이드를 바꾸며 특징맵 크기가 어떻게 달라지는지 확인했다.
- 입력 채널, 출력 채널과 필터 개수의 관계를 텐서 shape으로 살펴봤다.
- 합성곱, 풀링, 배치 정규화와 드롭아웃을 조합해 CNN을 구성했다.
- CIFAR-10에 랜덤 자르기와 좌우 반전, 정규화를 적용했다.

## 핵심 개념

합성곱은 작은 필터를 영상 전체에 움직이며 같은 가중치로 지역 특징을 찾는다. 완전연결층보다 파라미터를 적게 사용하면서 위치가 조금 달라져도 비슷한 패턴을 잡을 수 있다.

패딩은 가장자리 정보를 보존하고 출력 크기를 조절한다. 스트라이드는 필터가 이동하는 간격이며 값이 커질수록 특징맵이 빠르게 작아진다. 풀링도 공간 크기를 줄이지만 합성곱과 달리 학습하는 가중치는 없다.

## 실습 흐름

작은 텐서와 수동 필터로 합성곱 결과를 먼저 확인했다. 그다음 여러 합성곱 블록을 쌓고, 마지막 특징맵을 펼쳐 10개 클래스 출력으로 연결했다. CIFAR-10 데이터 변환과 DataLoader까지 준비한 뒤 모델의 입력·출력 크기가 맞는지 검사했다.

## 실행 상태

저장된 노트북은 데이터 준비와 모델 구조 확인까지 담고 있다. 최종 학습 정확도는 기록돼 있지 않으므로 성능을 비교하려면 학습 반복과 테스트 평가를 이어서 실행해야 한다.

## 다시 볼 것

- 출력 크기는 커널, 패딩, 스트라이드 값을 함께 넣어 계산한다.
- Flatten 이전의 채널과 공간 크기를 잘못 계산하면 선형층에서 shape 오류가 난다.
- 데이터 증강은 훈련 데이터에만 적용하고 테스트에는 결정적인 변환만 사용한다.
