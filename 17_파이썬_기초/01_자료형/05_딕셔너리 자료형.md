## 메모

- 딕셔너리는 어떻게 만들까?
- {key1: value1, key2: value2, ...}
- 딕셔너리의 키값으로 올 수 없는 데이터 타입은 리스트 -> mutable 이기 때문에
- 딕셔너리 쌍 추가하기
- 딕셔너리 요소 삭제하기
- 딕셔너리에 key를 사용해서 value 얻기
- 딕셔너리 관련 함수
- 1. key 리스트 만들기 - keys
- 2. value 리스트 만들기 - values
- 3. key, value 쌍얻기 - items

## 사용한 문법·함수

`print` · `type` · `list` · `a.keys` · `a.values` · `a.items` · `a.clear` · `a.get` · `a.pop`
