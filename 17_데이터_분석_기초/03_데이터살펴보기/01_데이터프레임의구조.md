## 메모

- 데이터 요약 정보 확인하기

- DataFrame객체.shape
- 데이터프레임의 기본 정보
- 자료형 알아보기
- 특정 필드의 데이터 타입 확인
- 데이터프레임의 기술 통계 정보 요약
- 데이터 개수 확인
- 각 열의 고유값 개수
- DataFrame객체["열이름"].value_counts()
