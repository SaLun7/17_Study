# 02. 회귀 분류 복습과 텍스트 증강

[← DAY2 목차](<README.md>) · [원본 노트북](<02_회귀 분류 복습과 텍스트 증강.ipynb>)

DAY1의 회귀·분류 코드를 복습한 뒤 문장에 변형을 주는 여러 텍스트 증강 방법을 비교했다.

## 핵심 개념

데이터 증강은 새로운 입력을 만들되 학습하려는 정답의 의미가 유지돼야 한다. 글자 삭제나 단어 위치 교환은 오탈자와 순서 변화에 대한 예제를 만들고, 문맥 기반 삽입과 동의어 치환은 다른 표현을 만든다. 역번역은 다른 언어로 번역했다가 돌아오는 방식이다.

텍스트는 작은 변화가 라벨을 바꾸기 쉽다. 코드의 예약어 치환 목록처럼 `can`을 `cannot`으로 바꾸면 표면적으로 비슷해도 뜻은 반대가 된다.

이미지는 조금 이동해도 같은 물체인 경우가 많지만, 문장은 단어 하나가 정답을 바꿀 수 있다. 특히 감정 분류에서 부정어를 삭제하거나 평점을 바꾸면 원래 라벨을 그대로 붙일 수 없다. 역번역 역시 자연스러움을 보장하지는 않으므로 원문·변형문·라벨을 함께 확인한다. 같은 원문에서 나온 변형들이 평가 자료에 섞이지 않도록 분할 후 증강하는 순서도 중요하다.

## 실습 흐름

회귀·이진 분류 부분을 다시 실행한 뒤 nlpaug로 BERT 기반 단어 삽입, 글자 삭제, 단어 교환, WordNet 동의어 치환, 예약어 치환, 영어·독일어 역번역을 적용한다. 원문과 변형 문장을 짝지어 읽는 것이 이 실습의 중심이다.

## 실행 결과

저장된 실행 출력은 없다. 증강된 문장 수가 늘어났다는 사실만으로 성능이 좋아졌다고 판단할 수는 없다. 각 변형이 원래 라벨을 보존하는지 먼저 확인해야 한다.

## 필요한 파일

앞부분의 `data/non_linear.csv`, `data/binary.csv`는 별도로 준비한다. 뒤의 문장 예제는 코드에 들어 있으며 NLTK 자료와 BERT·번역 모델은 실행 시 내려받아야 한다.

## 다시 볼 것

증강은 학습 데이터에만 적용하고 평가 데이터는 원래 분포로 남긴다. 부정어, 숫자, 고유명사가 바뀐 문장은 특히 주의해서 비교한다.
