# 01. PyTorch 회귀와 이진 분류

[← DAY1 목차](<README.md>) · [원본 노트북](<01_PyTorch 회귀와 이진 분류.ipynb>)

텐서와 자동 미분을 확인한 뒤 CSV를 읽는 Dataset, 미니배치 학습, 모델 저장까지 연결했다. 같은 학습 루프가 회귀와 이진 분류에서 어떻게 달라지는지 보는 실습이다.

## 핵심 개념

회귀 예제는 원래 입력 x에서 `[x², x]`를 만들어 선형층에 넣는다. 입력에 제곱항을 추가했기 때문에 선형층 하나로도 x에 대한 곡선 관계를 표현할 수 있다. 이진 분류는 세 개의 특성을 받아 sigmoid로 0~1의 값을 만든다.

Dataset은 샘플 하나의 입력과 정답을 정의하고 DataLoader는 이를 배치로 묶는다. 학습에서는 기울기를 초기화하고 순전파, 손실 계산, 역전파, 파라미터 갱신을 반복한다.

선형층이라는 이름은 입력 변수에 대한 직선만 만든다는 뜻이 아니라, 주어진 특성의 가중합을 계산한다는 뜻이다. `[x², x]`를 넣으면 출력은 x에 대한 이차식이 된다. 이진 분류에서는 sigmoid 출력과 정답 0·1을 비교해 손실을 계산하고, 실제 클래스 선택에는 별도의 임계값을 적용한다. 손실을 줄이는 과정과 클래스를 고르는 과정을 나눠 보면 회귀와 분류의 차이가 읽힌다.

## 실습 흐름

GPU 사용 여부와 텐서 연산을 살펴본 뒤 데이터를 학습·검증·테스트로 나눈다. 회귀 학습과 평가 후 모델 전체 및 state_dict 저장 방식을 비교하고, 별도 CSV로 이진 분류를 학습한다.

## 실행 결과

현재 저장본에는 실행 출력이 없다. 코드가 정의한 학습·평가 흐름을 정리한 자료이며, 회귀 오차나 분류 정확도는 재실행해 확인해야 한다.

## 필요한 파일

과정 루트의 `data/non_linear.csv`와 `data/binary.csv`가 필요하지만 현재 저장소에는 없다. 전자는 앞의 두 열을 x와 y로, 후자는 앞의 세 열을 입력으로, 네 번째 열을 정답으로 읽는다. `models/model.pt`, `models/model_state_dict.pt`는 실행 중 생성하는 파일이다.

## 다시 볼 것

모델 구조와 입력 열 순서는 가중치를 다시 불러올 때도 같아야 한다. 학습·검증·테스트 변수가 뒤쪽 셀에서 다시 정의되므로 각 실습 블록을 순서대로 실행한다.
