# 10. GPT-2 생성과 BERT BART 활용

[← DAY4 목차](<README.md>) · [원본 노트북](<10_GPT-2 생성과 BERT BART 활용.ipynb>)

GPT-2 문장 생성으로 시작하지만 뒤에는 BERT 감정 분류와 BART 뉴스 요약까지 들어 있다. 세 모델의 목적이 드러나도록 제목을 바꿨다.

## 핵심 개념

GPT-2는 앞의 문맥을 이어 쓸 다음 토큰을 예측한다. BERT 분류기는 입력 문장을 읽고 클래스 점수를 만들며, BART는 인코더·디코더를 사용해 입력 기사에서 요약 문장을 생성한다. 같은 Transformer 계열이어도 입력·정답·출력 형식이 다르다.

분류에서는 정확도를, 요약에서는 참조 요약과 생성 결과의 겹침을 보는 ROUGE를 사용한다. 서로 다른 과제의 점수를 직접 비교하지 않는다.

## 실습 흐름

GPT-2에 영어 시작 문장을 넣고 여러 출력을 확인한다. NSMC 일부로 다국어 BERT 분류 데이터 로더를 만들고, 뉴스 기사·요약 쌍으로 BART 데이터 로더와 학습·평가 함수를 구성한다. 요약 정답의 padding은 손실에서 제외한다.

## 실행 결과

저장된 BERT 평가 정확도는 0.82이고 BART 평가에서는 손실 약 1.823과 ROUGE 계산값 약 0.256이 출력됐다. 다만 두 학습 루프가 주석 처리돼 있고 평가 셀은 로컬 체크포인트를 읽는다. 저장된 결과가 있다고 새 환경에서도 곧바로 같은 평가를 실행할 수 있는 것은 아니다.

## 필요한 파일

`models/BertForSequenceClassification.pt`, `models/BartForConditionalGeneration.pt`는 저장소에 없다. 같은 코드로 학습해 만들거나 별도로 준비해야 한다. NSMC와 `argilla/news-summary`는 실행 중 내려받는다.

## 다시 볼 것

GPT-2 출력은 생성 예시이지 사실 검증 결과가 아니다. 분류 head의 신규 초기화 경고와 실제 미세조정된 체크포인트 사용 여부를 구분한다.
