# 06. Word2Vec 임베딩 LSTM 감정 분류

[← DAY3 목차](<README.md>) · [원본 노트북](<06_Word2Vec 임베딩 LSTM 감정 분류.ipynb>)

앞에서 만든 Word2Vec 벡터를 LSTM 분류기의 임베딩 초기값으로 사용하는 실습이다.

## 핵심 개념

사전학습 임베딩을 사용할 때는 현재 분류 데이터의 어휘 순서에 맞춰 벡터 행렬을 다시 만들어야 한다. 단어가 없을 때의 처리와 padding 행도 함께 맞춘다. `Embedding.from_pretrained`의 고정 여부는 분류 학습 중 단어 벡터까지 바꿀지 결정한다.

LSTM은 임베딩 시퀀스를 읽고 문장 단위의 점수를 만든다. 길이를 맞추기 위한 padding과 실제 문장의 마지막 위치는 같지 않을 수 있으므로 최종 특징을 꺼내는 방식을 확인해야 한다.

사전학습 임베딩을 고정하면 분류 데이터가 적을 때 기존 단어 표현을 유지할 수 있다. 함께 학습하면 영화 리뷰에서의 쓰임에 맞게 벡터가 달라지지만, 작은 자료에 과하게 맞춰질 수도 있다. 둘 중 하나가 항상 낫다기보다 같은 분할에서 검증 결과를 비교할 대상이다. 어휘에 없는 단어와 패딩을 같은 ID로 처리하면 모델이 둘을 구분하지 못한다.

## 실습 흐름

NSMC를 나누고 Okt 토큰화, 어휘 사전, 정수 인코딩, 패딩을 적용한다. Word2Vec 모델에서 분류 어휘에 해당하는 벡터를 가져와 임베딩층을 만들고 순환 신경망과 이진 분류 손실을 연결한다.

## 실행 결과

저장 출력에는 데이터 로더 길이가 남아 있지만 학습 완료 후의 분류 성능은 기록돼 있지 않다. 실행 시간이 긴 전처리·학습과 구조 확인을 구분해서 읽는다.

## 필요한 파일

과정 루트의 `models/word2vec.model`을 사용한다. 파일은 포함돼 있으며 직접 다시 만들려면 같은 DAY의 Word2Vec 실습을 먼저 실행한다. NSMC는 별도로 내려받는다.

## 다시 볼 것

사전학습 벡터를 쓴 결과와 무작위 초기화 결과를 비교하려면 데이터 분할과 다른 설정을 같게 유지해야 한다.
