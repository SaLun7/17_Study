# 08. 위치 인코딩과 번역 데이터 준비

[← DAY3 목차](<README.md>) · [원본 노트북](<08_위치 인코딩과 번역 데이터 준비.ipynb>)

Transformer 번역 모델을 만들기 전, 토큰 임베딩에 순서 정보를 더하고 독일어·영어 어휘를 준비하는 단계다.

## 핵심 개념

attention만으로는 입력 토큰의 순서를 구분하는 장치가 부족하므로 위치 정보를 별도로 더한다. 여기서는 위치와 임베딩 차원에 따라 주기가 다른 sine·cosine 값을 만들어 입력 벡터에 더한다.

번역은 입력 언어와 출력 언어가 다르므로 토크나이저와 어휘 사전도 각각 만든다. `<unk>`, `<pad>`, `<bos>`, `<eos>`는 미등록 단어, 길이 맞춤, 문장 시작과 끝을 표현한다.

## 실습 흐름

위치 인코딩을 색으로 그려 위치·차원별 패턴을 확인한다. Multi30k의 독일어·영어 문장을 spaCy로 토큰화하고 언어별 어휘를 만든 뒤 위치 인코딩과 TokenEmbedding 클래스를 정의한다.

## 실행 결과

이 파일은 번역 모델 전체 학습 전의 준비 단계다. 번역 결과나 BLEU 점수는 없다. 인코더·디코더와 학습 루프는 DAY4의 Transformer 노트북으로 이어진다.

## 필요한 파일

Multi30k 데이터와 spaCy의 `de_core_news_sm`, `en_core_web_sm`이 필요하다. 과정에 포함된 `torchtext` 호환 모듈을 찾을 수 있도록 과정 루트를 모듈 경로에 추가했다.

## 다시 볼 것

위치 인코딩의 첫 축이 시퀀스 길이인지 배치인지 확인한다. 언어별 어휘 사전과 특수 토큰 번호는 뒤의 번역 모델에서도 같은 설정을 사용해야 한다.
