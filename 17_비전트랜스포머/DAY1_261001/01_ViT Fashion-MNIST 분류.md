# 01. ViT Fashion-MNIST 분류

[← DAY1 목차](<README.md>) · [원본 노트북](<01_ViT Fashion-MNIST 분류.ipynb>)

Fashion-MNIST를 사전학습 ViT의 입력 규격에 맞춰 변환하고 의류 10개 클래스로 미세조정했다.

## 핵심 개념

ViT는 이미지를 패치로 나눠 토큰처럼 처리한다. 224×224 이미지를 16×16 패치로 나누면 196개가 되고, 분류용 토큰까지 더하면 197개 토큰이 된다. 위치 임베딩은 패치가 이미지의 어느 위치에 있었는지 알려준다.

Fashion-MNIST는 흑백이지만 사전학습 모델은 3채널 이미지를 받는다. 여기서는 같은 채널을 세 번 이어 붙이고 모델에 맞는 크기와 정규화를 적용한다. 채널을 복제해도 새로운 색 정보가 생기는 것은 아니다.

패치를 작게 나누면 작은 부분을 세밀하게 표현하지만 토큰 수가 늘어 attention 계산량도 커진다. 흑백 28×28 이미지를 224×224로 키워도 원본에 없던 세부 정보가 생기지는 않는다. 여기서 크기를 키우는 이유는 사전학습 모델의 입력 조건을 맞추기 위해서다. 새 분류층은 의류 라벨을 처음 배우므로 본체의 사전학습 성능과 구분해 읽는다.

## 실습 흐름

클래스마다 학습 1,000장과 평가 100장을 뽑아 총 10,000장·1,000장을 사용한다. `AutoImageProcessor` 설정으로 변환하고 분류층을 10개 출력으로 교체한다. Trainer로 3 epoch 학습한 뒤 macro F1과 혼동행렬을 확인한다.

## 실행 결과

패치 임베딩 출력은 `(32, 196, 768)`, 분류 토큰 포함 출력은 `(32, 197, 768)`이다. 저장된 평가 F1은 약 0.9196, 손실은 약 0.4712다. 전체 Fashion-MNIST가 아닌 선택한 표본의 결과다.

## 필요한 파일

Fashion-MNIST는 자동으로 내려받아 과정 루트의 `datasets/`에 둔다. 사전학습 모델도 최초 실행 시 다운로드한다. 학습 결과는 `models/ViT-FashionMNIST/`에 생성하며 Git에서 제외한다.

## 다시 볼 것

평가용 표본을 최적 체크포인트 선택에도 사용하고 있어 완전히 독립된 최종 테스트는 아니다. 모델 구조 비교에서는 표본, 전처리, 학습 조건을 함께 적어 둔다.
