# 02. Swin Transformer Fashion-MNIST 분류

[← DAY2 목차](<README.md>) · [원본 노트북](<02_Swin Transformer Fashion-MNIST 분류.ipynb>)

DAY1과 같은 의류 분류 문제를 Swin Transformer로 학습했다. 전체 패치를 한 번에 보는 방식과 창 단위 attention의 차이를 살펴본다.

## 핵심 개념

Swin은 작은 window 안에서 attention을 계산하고 다음 블록에서 window 위치를 옮겨 다른 영역의 정보를 연결한다. 단계가 올라가면서 패치를 합쳐 해상도를 낮추고 특징 차원을 늘리는 계층 구조를 사용한다.

모델을 바꾸면 사전학습 때의 입력 정규화도 함께 확인해야 한다. 데이터와 출력 클래스가 같더라도 ViT의 처리 설정을 그대로 복사하는 것은 피한다.

ViT는 전체 패치 사이의 관계를 한 번에 보지만 Swin은 창 내부에서 시작해 계층적으로 정보를 모은다. 창의 크기를 고정하면 고해상도 입력에서 전체 attention의 부담을 줄일 수 있다. 의류 분류 결과가 비슷해도 두 구조가 정보를 모으는 방식은 다르므로, 점수뿐 아니라 모델의 계산량과 입력 해상도를 함께 비교한다.

## 실습 흐름

Fashion-MNIST에서 클래스별 표본을 고르고 Swin의 이미지 처리 설정으로 3채널·224×224 입력을 만든다. 사전학습 분류층을 10개 클래스로 바꾸고 3 epoch 학습한다. 가장 좋은 F1의 체크포인트를 읽어 혼동행렬을 그린다.

## 실행 결과

저장된 평가 F1은 약 0.9160, 손실은 약 0.2419다. 학습 시간 기록은 약 278초지만 장비와 환경에 따라 달라진다. ViT와 비교할 때 손실값 하나만으로 우열을 판단하지 않는다.

## 필요한 파일

Fashion-MNIST와 사전학습 모델은 내려받아 사용한다. 데이터는 과정 루트의 `datasets/`, 결과는 `models/Swin-FashionMNIST/`에 둔다.

## 다시 볼 것

macro F1은 각 클래스의 F1을 같은 비중으로 평균낸 값이다. 혼동행렬로 비슷한 의류끼리 어떤 혼동이 있는지 확인하고, 독립 테스트셋이 필요한지도 구분한다.
