# 13. Faster R-CNN과 YOLO 객체 검출

[← DAY4 목차](<README.md>) · [원본 노트북](<13_Faster R-CNN과 YOLO 객체 검출.ipynb>)

사전학습 Faster R-CNN으로 바로 객체를 찾는 과정과 PASCAL VOC 데이터로 YOLO 형태의 모델을 직접 구성하는 과정을 한 노트북에 정리했다.

## Faster R-CNN 추론

TensorFlow Hub의 Faster R-CNN ResNet50 모델과 COCO 라벨맵을 불러왔다. Faster R-CNN은 먼저 객체가 있을 만한 영역을 제안하고, 그 후보마다 클래스와 박스 위치를 다시 예측하는 2단계 검출 모델이다. 속도보다는 비교적 정확한 위치 검출이 중요한 경우에 기준 모델로 사용할 수 있다.

예제 사진을 RGB 배열과 batch 형태로 바꿔 모델에 넣었다. 출력에는 박스 좌표, 클래스 번호와 신뢰도가 들어 있으며 COCO 라벨맵을 이용해 번호를 사람이 읽을 수 있는 이름으로 바꿨다. 일정 신뢰도 이상의 결과만 원본 영상 위에 표시했다.

## PASCAL VOC 데이터 준비

VOC 2007의 훈련·검증 자료와 테스트 자료를 내려받아 DAY4의 `data` 폴더에 압축 해제한다. 각 JPEG 이미지에는 같은 이름의 XML 어노테이션이 있고, XML에는 객체 클래스와 박스의 왼쪽 위·오른쪽 아래 좌표가 기록돼 있다.

노트에서는 이 좌표를 224×224 입력 기준으로 바꾸고, 영상 전체를 7×7 grid로 나눠 객체 중심이 들어간 cell에 클래스와 박스 정보를 저장했다. 배경 cell과 객체 cell의 수가 크게 다르기 때문에 객체 존재 여부와 위치, 클래스 손실을 나눠 계산한다.

## YOLO 형태 모델

ImageNet 사전학습 VGG16을 특징 추출부로 사용하고 뒤에 검출용 합성곱층과 Dense 층을 붙였다. 출력은 각 grid cell의 박스 좌표, 신뢰도와 클래스 점수로 해석한다. 학습 중 가장 좋은 검증 모델은 `yolo.h5`로 저장한다.

마지막 시각화에서는 예측 좌표를 원본 이미지 크기로 되돌리고 신뢰도가 높은 박스를 그린다. 현재 코드의 `nms` 함수는 이름과 달리 겹치는 박스를 IoU로 제거하지 않고 신뢰도 기준으로만 거른다. 실제 NMS와 비교하려면 IoU가 큰 중복 박스를 제거하는 과정이 추가로 필요하다.

## 실습 흐름

먼저 사전학습 Faster R-CNN으로 예제 사진을 검출해 완성된 모델의 입력과 출력 형태를 확인했다. 이후 VOC 자료를 내려받아 이미지와 XML을 직접 학습 배열로 바꾸고, VGG16 기반 YOLO 형태 모델과 손실 함수를 구성했다. 학습이 끝나면 저장된 모델로 한 장을 예측하고 박스를 원본 크기에 맞춰 그리는 순서다.

## 실행 상태와 경로

PASCAL VOC 압축 파일과 학습 데이터, `yolo.h5`, `output.jpg`는 용량이나 재생성 가능 여부 때문에 Git에서 제외한다. 객체 검출 API는 컴퓨터 비전 폴더의 `models` 서브모듈을 사용한다. VOC 데이터는 DAY4의 `data`에 저장하고 이후 셀도 같은 위치를 읽도록 경로를 맞췄다. 마지막 셀은 DAY1의 `like_lenna.png`를 직접 불러온다.

## 다시 볼 것

- 박스 좌표가 절대 좌표인지 0~1 정규화 좌표인지 구분한다.
- 데이터의 클래스 수와 모델 출력 채널 수가 일치하는지 확인한다.
- 전체 120 epoch 학습은 오래 걸리므로 작은 일부 데이터로 shape과 손실부터 점검한다.
