# 03. 주파수 변환과 에지 검출

[← DAY2 목차](<README.md>) · [원본 노트북](<03_주파수 변환과 에지 검출.ipynb>)

FFT, Gaussian pyramid, Canny와 Sobel을 이용해 영상을 주파수·해상도·기울기 관점에서 분석한다.

## 핵심 개념

### 저주파

영상의 완만한 밝기 변화와 큰 구조를 담는다.

### 고주파

빠른 변화인 경계와 세부정보, 노이즈를 포함한다.

### Sobel

x/y 방향의 기울기를 계산한다.

### Canny

평활화와 비최대 억제, 이중 임계값으로 얇고 연결된 경계를 만든다.

저주파만 남기면 큰 형태는 유지되지만 작은 질감과 경계가 흐려진다. 반대로 고주파를 강조하면 에지도 두드러지지만 노이즈까지 커질 수 있다. Canny와 Sobel의 결과 차이는 단순히 어느 쪽이 더 선명한지가 아니라 평활화와 임계값 처리까지 포함해 읽어야 한다.

## 실습 흐름

그레이스케일 영상을 FFT로 주파수 영역에 옮기고 중앙에 저주파가 모이도록 이동해 스펙트럼을 확인했다. 저주파 영역만 남긴 뒤 역변환해 영상이 부드러워지는 모습을 비교했다. 이어서 Gaussian pyramid로 해상도를 단계적으로 줄이고, Sobel의 방향별 기울기와 Canny의 얇은 경계를 같은 영상에서 살펴봤다.

### 사용한 함수

| 함수·클래스 | 역할 |
|---|---|
| `cv2.imread` | 파일에서 영상 배열 읽기 |
| `cv2.resize` | 영상 크기 변경 |
| `cv2.getRotationMatrix2D` | 2차원 회전 변환행렬 생성 |
| `cv2.warpAffine` | Affine 변환 적용 |
| `cv2.Canny` | Canny 에지 검출 |
| `cv2.Sobel` | Sobel 방향 기울기 계산 |
| `np.fft.fft2` | 2차원 푸리에 변환 |

## 실행 결과

저주파만 통과시키면 영상이 부드러워지고, 고주파를 강조하면 경계와 노이즈가 함께 강해진다. Canny 임계값은 경계 누락과 잡음 검출의 균형이다.
