## 핵심 메모

### 저주파

영상의 완만한 밝기 변화와 큰 구조를 담는다.

### 고주파

빠른 변화인 경계와 세부정보, 노이즈를 포함한다.

### Sobel

x/y 방향의 기울기를 계산한다.

### Canny

평활화와 비최대 억제, 이중 임계값으로 얇고 연결된 경계를 만든다.

image = cv2.imread("like_lenna.png", cv2.IMREAD_COLOR)
img_rgb = cv2.cvtColor(image, cv2.COLOR_BGR2RGB)

def gussian_pyramid(image, levels):
    pyramid = [image]
    for i in range(levels - 1):
        image = cv2.pyrDown(image)
        pyramid.append(image)
    return pyramid

def laplacian_pyramid(gussian_pyramid):
    laplacian = []
    for i in range(len(gussian_pyramid) - 1):
        next_level = cv2.pyrUp(gussian_pyramid[i + 1])
        if next_level.shape[0] > gussian_pyramid[i].shape[0]:
            next_level = next_level[:-1, :, :]

        if next_level.shape[1] > gussian_pyramid[i].shape[1]:
            next_level = next_level[:, : -1, :]

        lap = cv2.subtract(gussian_pyramid[i], next_level)
        laplacian.append(lap)

    laplacian.append(gussian_pyramid[-1])

    return laplacian

levels = 5

g_pyramid = gussian_pyramid(img_rgb, levels)
l_pyramid = laplacian_pyramid(g_pyramid)

## 결과 메모

저주파만 통과시키면 영상이 부드러워지고, 고주파를 강조하면 경계와 노이즈가 함께 강해진다. Canny 임계값은 경계 누락과 잡음 검출의 균형이다.

## 사용한 함수

| 함수·클래스 | 역할 |
|---|---|
| `cv2.imread` | 파일에서 영상 배열 읽기 |
| `cv2.resize` | 영상 크기 변경 |
| `cv2.getRotationMatrix2D` | 2차원 회전 변환행렬 생성 |
| `cv2.warpAffine` | Affine 변환 적용 |
| `cv2.Canny` | Canny 에지 검출 |
| `cv2.Sobel` | Sobel 방향 기울기 계산 |
| `np.fft.fft2` | 2차원 푸리에 변환 |

## 정리

- FFT 마스크와 공간 영상 결과를 함께 본다.
- Canny 전 평활화의 영향을 확인한다.
- Sobel x/y 방향과 magnitude를 구분한다.
