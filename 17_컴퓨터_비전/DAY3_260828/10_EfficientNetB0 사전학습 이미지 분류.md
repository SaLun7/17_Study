# 10. EfficientNetB0 사전학습 이미지 분류

[← DAY3 목차](<README.md>) · [원본 노트북](<10_EfficientNetB0 사전학습 이미지 분류.ipynb>)

ResNet50에 사용한 것과 같은 강아지 사진을 ImageNet 사전학습 EfficientNetB0으로 분류하고 두 모델의 결과와 크기를 비교했다.

## 핵심 개념

EfficientNet은 모델을 크게 만들 때 깊이만 늘리거나 채널 수만 넓히지 않는다. 네트워크 깊이, 채널 너비와 입력 해상도를 일정한 비율로 함께 조절하는 compound scaling을 사용해 정확도와 계산량의 균형을 맞춘다. B0은 이 계열의 기준 모델이며 더 큰 B1~B7 모델의 출발점이 된다.

이 실습도 `include_top=True`로 ImageNet 1,000개 클래스 출력층을 그대로 사용했다. 새로운 강아지 품종 데이터로 학습한 것이 아니라, 모델이 이미 배운 클래스 중 사진과 가장 가까운 항목을 찾은 결과다.

## 실습 흐름

DAY3 폴더의 `dog.png`를 불러와 224×224 크기로 맞추고 배치 형태로 변환했다. EfficientNetB0 전용 전처리를 거쳐 예측한 뒤 상위 세 클래스와 확률을 출력했다. 모델 요약에서는 층 구성과 전체 파라미터 수도 확인했다.

## 실행 결과

| 예측 | 확률 |
|---|---:|
| toy poodle | 54.50% |
| miniature poodle | 34.10% |
| standard poodle | 3.68% |

전체 파라미터는 약 533만 개다. ResNet50과 1순위 품종은 달랐지만 두 모델 모두 상위 세 결과를 푸들 계열로 예측했다. 한 장의 결과만으로 모델 우열을 정할 수는 없지만 모델마다 확률을 나누는 방식이 다르다는 점은 확인할 수 있다.

## 다시 볼 것

- 여러 모델을 비교할 때는 같은 이미지와 같은 평가 기준을 사용한다.
- 파라미터 수 외에도 실제 추론 시간과 메모리 사용량을 측정한다.
- 사전학습 모델에 새 클래스를 붙일 때는 `include_top=False`로 특징 추출부만 사용한다.
