# 08. CIFAR-10 GoogLeNet 구현

[← DAY3 목차](<README.md>) · [원본 노트북](<08_CIFAR-10 GoogLeNet 구현.ipynb>)

CIFAR-10에 맞춰 GoogLeNet의 핵심인 Inception 모듈을 함수형 API로 직접 구성했다.

## 정리

- 한 입력에 1×1, 3×3, 5×5 합성곱과 풀링 경로를 나란히 적용한다.
- 각 경로의 결과를 채널 방향으로 합쳐 여러 크기의 특징을 한 번에 사용한다.
- 합성곱 뒤에 Batch Normalization과 ReLU를 붙였다.
- L2 가중치 감쇠, SGD momentum, 학습률 감소 콜백을 사용해 40 epoch 학습했다.

1×1 합성곱은 채널 수를 줄여 뒤의 큰 커널 계산량을 낮추는 역할도 한다. Inception 모듈은 한 종류의 필터 크기만 고르는 대신 여러 크기의 특징을 동시에 보게 한다.

## 실행 결과

테스트 손실은 약 `0.7862`, 정확도는 `88.02%`로 기록돼 있다. DAY3의 직접 학습 모델 가운데 가장 높은 결과다.

학습 시간이 길기 때문에 다시 실행할 때는 GPU 사용 여부와 학습률 변화부터 확인하는 편이 좋다.
