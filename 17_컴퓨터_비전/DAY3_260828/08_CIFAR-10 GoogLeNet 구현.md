# 08. CIFAR-10 GoogLeNet 구현

[← DAY3 목차](<README.md>) · [원본 노트북](<08_CIFAR-10 GoogLeNet 구현.ipynb>)

CIFAR-10에 맞춰 GoogLeNet의 핵심인 Inception 모듈을 Keras 함수형 API로 직접 구성하고 처음부터 학습했다.

## 핵심 개념

일반적인 CNN 블록은 한 가지 크기의 필터를 순서대로 적용한다. Inception 모듈은 같은 입력에 1×1, 3×3, 5×5 합성곱과 풀링을 나란히 적용한 뒤 결과를 채널 방향으로 합친다. 한 단계에서 작은 무늬와 넓은 형태를 동시에 볼 수 있다는 것이 핵심이다.

1×1 합성곱은 공간 크기를 바꾸지 않으면서 채널을 섞는다. 3×3이나 5×5 합성곱 앞에서 채널 수를 먼저 줄이면 큰 커널의 계산량과 파라미터 수를 낮출 수 있다.

## 모델 구성

- 각 합성곱 뒤에 Batch Normalization과 ReLU를 적용했다.
- 여러 Inception 모듈 사이에서 풀링으로 특징맵 크기를 줄였다.
- 마지막에는 Average Pooling으로 특징맵을 줄이고 Flatten과 분류층으로 10개 클래스를 예측했다.
- L2 가중치 감쇠와 SGD momentum을 사용했다.
- 검증 성능이 정체될 때 학습률을 낮추는 콜백을 적용했다.

## 실습 흐름

CIFAR-10을 정규화하고 훈련·검증 데이터로 나눈 뒤 Inception 모듈 함수를 만들었다. 함수형 API로 여러 갈래의 출력을 연결하고 전체 모델 shape을 확인했다. 이후 40 epoch 학습하면서 정확도와 손실 변화를 기록하고 테스트 데이터로 최종 성능을 평가했다.

## 실행 결과

저장된 결과의 테스트 손실은 약 `0.7862`, 정확도는 `88.02%`다. DAY3에서 CIFAR-10을 직접 학습한 모델 가운데 가장 높은 결과로 기록돼 있다. MLP나 단순 CNN보다 구조와 학습 시간이 늘어난 만큼 실제 성능 개선이 있었는지 비교할 수 있다.

## 다시 볼 것

- 여러 갈래 출력을 합칠 때 높이와 너비가 같은지 확인한다.
- 1×1 합성곱을 제거했을 때 파라미터와 연산량이 얼마나 늘어나는지 비교한다.
- 다시 학습할 때는 GPU 사용 여부와 epoch별 학습률부터 확인한다.
