# 09. ResNet50 사전학습 이미지 분류

[← DAY3 목차](<README.md>) · [원본 노트북](<09_ResNet50 사전학습 이미지 분류.ipynb>)

ImageNet으로 미리 학습된 ResNet50을 불러와 별도의 재학습 없이 강아지 사진 한 장을 분류했다.

## 사전학습 모델

ImageNet은 1,000개 사물 클래스로 구성된 대규모 이미지 데이터셋이다. 사전학습 모델은 이 데이터에서 모서리, 질감, 형태와 같은 특징을 이미 배운 상태다. `include_top=True`를 사용해 ImageNet의 1,000개 출력층까지 그대로 불러왔기 때문에 현재 실습은 새로운 클래스를 학습하는 전이학습이 아니라 기존 모델로 바로 추론하는 과정이다.

ResNet의 핵심은 블록 입력을 합성곱 출력에 더하는 잔차 연결이다. 깊은 층을 통과할 때도 정보와 기울기가 shortcut으로 이동할 수 있어 매우 깊은 모델을 안정적으로 학습하는 데 도움을 준다.

## 실습 흐름

`dog.png`를 읽어 224×224 크기로 맞추고 배치 차원을 추가했다. 그다음 ResNet50 전용 `preprocess_input`을 적용해 모델이 학습할 때 사용한 픽셀 기준에 맞췄다. 예측값은 1,000개 클래스의 확률이며 `decode_predictions`로 상위 세 결과를 이름과 함께 확인했다.

## 실행 결과

| 예측 | 확률 |
|---|---:|
| miniature poodle | 66.01% |
| toy poodle | 29.69% |
| standard poodle | 1.59% |

세 결과가 모두 푸들 계열로 나와 사진의 주요 특징을 일관되게 잡은 것을 확인했다. 다만 1순위 확률만으로 모델이 완전히 확신한다고 해석하기보다 상위 후보가 어떤 범주에 모이는지 함께 보는 편이 좋다.

## 다시 볼 것

- 모델마다 입력 크기와 전처리 함수가 다르므로 같은 이름의 함수를 확인한다.
- OpenCV와 PIL은 색상 채널 순서가 다를 수 있다.
- 처음 실행할 때 약 100MB의 가중치를 내려받으며 `dog.png`는 현재 DAY3 폴더에 있다.
