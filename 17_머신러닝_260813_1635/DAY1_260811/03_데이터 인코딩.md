# 03. 데이터 인코딩

문자열 범주를 머신러닝 모델이 처리할 수 있는 숫자 표현으로 바꾸고 인코딩 방식의 차이를 비교한다.

[← 과정 목차](<../README.md>) · [원본 노트북](<03_데이터 인코딩.ipynb>)

## 실습 내용

- LabelEncoder와 OneHotEncoder의 출력 차이를 이해한다.
- 명목형과 순서형 범주를 구분한다.
- 학습 데이터에 fit한 인코더를 평가 데이터에 재사용한다.

**데이터**  
가전제품 범주 예제와 pandas DataFrame

## 핵심 메모

### 레이블 인코딩

각 범주에 정수 하나를 부여한다. 입력 피처에 쓰면 크기 관계가 있다고 오해될 수 있다.

### 원-핫 인코딩

범주마다 별도 열을 만들고 해당 범주만 1로 표시한다.

### 알 수 없는 범주

평가 시 새 범주가 나타날 수 있으므로 handle_unknown 전략이 필요하다.

## 코드

코드는 길어서 중요한 셀만 접어 두었다. 전체 실행 과정은 원본 노트북에서 확인한다.

<details>
<summary>코드 셀 1 보기</summary>

```python
from sklearn.preprocessing import LabelEncoder

items = ["TV", "냉장고", "컴퓨터", "선풍기", "선풍기", "에어컨", "에어컨"]

encoder = LabelEncoder()
encoder.fit(items)
labels = encoder.transform(items)
print(labels)
```

</details>

<details>
<summary>코드 셀 2 보기</summary>

```python
from sklearn.preprocessing import OneHotEncoder
import numpy as np

items = ["TV", "냉장고", "컴퓨터", "선풍기", "선풍기", "에어컨", "에어컨"]

items = np.array(items).reshape(-1, 1)

oh_encoder = OneHotEncoder()
oh_encoder.fit(items)
oh_labels = oh_encoder.transform(items)

print(oh_labels.toarray())
print(oh_labels.shape)
```

</details>

## 결과 메모

인코딩 결과의 숫자는 범주의 의미가 아니라 표현 방식이다. 명목형 입력은 원-핫 인코딩을 기본으로 보고, 순서가 실제 의미를 가질 때만 순서형 인코딩을 사용한다.

## 사용한 함수

| 함수·클래스 | 역할 |
|---|---|
| `LabelEncoder` | 범주를 정수 라벨로 변환 |
| `OneHotEncoder` | 범주별 0/1 열 생성 |

## 정리

- 인코더는 학습 데이터에만 fit한다.
- 숫자 크기에 실제 순서 의미가 있는지 확인한다.
- 범주 수가 많으면 차원 증가와 희소성을 고려한다.
