# 코드봇 코드 이어쓰기 웹서비스 PRD

## 1. 제품 개요

사용자가 Python 코드의 앞부분을 입력하고 **생성** 버튼을 누르면, 기존 코드봇이 이어서 만든 코드를 화면에 보여주는 웹서비스다. 회원가입이나 로그인 없이 사용할 수 있다. 이번 버전의 목적은 기존 코드봇을 웹에서 호출해 결과를 확인하는 최소 기능을 구현하는 것이다.

## 2. 대상 사용자와 사용 시나리오

- 대상: 짧은 Python 코드 조각의 뒷부분을 코드봇으로 생성해 보고 싶은 사용자.
- 시나리오: 사용자가 코드 입력창에 `def`와 같은 코드 앞부분을 적고 생성 버튼을 누른다. 서비스는 입력을 검증하고 코드봇을 호출한 뒤, 사용자가 작성한 앞부분과 생성된 뒷부분을 합친 전체 코드를 표시한다.

## 3. 목표와 완료 기준

### 목표

기존 Python 코드봇의 코드 이어쓰기 기능이 React 화면과 FastAPI 서버를 통해 한 번의 요청으로 동작하는지 확인한다.

### 최소 완료 기준

1. 사용자가 로그인 없이 페이지에 접속할 수 있다.
2. 유효한 코드 앞부분을 입력하고 버튼을 누르면 기존 `model_pretrain.pt`의 생성 결과가 전체 코드에 포함되어 화면에 표시된다.
3. 기존 토크나이저 기준 56토큰 입력은 허용하고 57토큰 입력은 생성 전에 거부한다.
4. 빈 입력과 공백뿐인 입력은 거부한다.
5. 생성 한도는 요청당 최대 200토큰이며, 입력과 생성 한도의 합이 모델 문맥 길이 256토큰을 넘지 않는다.
6. 입력 오류나 생성 실패 시 사용자가 이유를 알 수 있고 페이지에서 다시 시도할 수 있다.

## 4. 사용자 흐름

1. 사용자가 코드 입력창에 Python 코드의 앞부분을 작성한다.
2. 사용자가 생성 버튼을 누른다.
3. 서비스가 입력의 토큰 수를 검증한다. 유효하지 않으면 오류를 표시하고 생성하지 않는다.
4. 유효한 입력이면 기존 코드봇이 이어지는 코드를 생성한다.
5. 서비스가 입력과 생성 결과를 합친 전체 코드를 화면에 표시한다. 줄바꿈과 들여쓰기는 유지한다.

## 5. 기능 요구사항

| ID | 요구사항 |
| --- | --- |
| FR-01 | 화면은 코드 입력창, 생성 버튼, 결과 영역으로 구성한다. |
| FR-02 | 로그인 없이 생성 요청을 보낼 수 있다. |
| FR-03 | 입력 제한은 글자 수가 아닌 기존 `BPETokenizer.encode()` 결과의 토큰 수로 판정한다. 서버가 최종 검증한다. |
| FR-04 | 공백뿐인 입력과 56토큰 초과 입력은 거부하고, 사용자에게 이유를 표시한다. |
| FR-05 | 유효한 입력은 명령문 템플릿을 붙이지 않고 코드 앞부분 그대로 모델에 전달한다. |
| FR-06 | 기존 코드봇으로 최대 200개의 새 토큰을 생성한다. |
| FR-07 | 결과 영역에는 사용자 입력과 생성 결과를 합친 전체 코드를 표시한다. |
| FR-08 | 요청 처리 중에는 생성 버튼의 중복 요청을 막고, 실패 시 오류를 표시한다. |

## 6. 기술 제약 및 기존 자산 사용

- 프론트엔드는 **React**, 백엔드는 **FastAPI**를 사용한다.
- 새 모델을 만들거나 다른 생성 서비스를 호출하지 않는다. 이 저장소의 `model_pretrain.pt`, `merge_rules.pkl`, `model.py`, `tokenizer.py`, `utils.py`를 사용한다.
- 서버 시작 시 `GPT.load_from()`으로 모델을, `BPETokenizer.load_from()`으로 토크나이저를 로드한다. 요청마다 다시 로드하지 않는다.
- 추론에는 기존 `utils.generate()`를 사용하고 `max_new_tokens=200`, `temperature=1.0`을 명시한다. 이 함수는 입력을 포함한 전체 문자열을 반환한다.
- 모델의 문맥 길이는 `04.ipynb` 학습 설정상 256토큰이다. 서비스 시작 시 로드한 모델의 `max_context_len`이 256인지 확인한다. 사용자 입력은 최대 56토큰으로 제한해 생성 한도 200토큰과 합쳐 256토큰 이내로 유지한다.
- 서버 실행 환경에는 기존 코드가 요구하는 PyTorch, `regex` 등의 Python 의존성이 있어야 한다. 모델이나 토크나이저를 로드하지 못하면 서비스 준비 실패를 드러낸다.

## 7. 이번 버전의 범위 밖

회원가입·로그인, 사용자별 기록 저장, 생성 코드 실행, 파일 업로드, 모델 선택·재학습, 채팅 기능은 포함하지 않는다.

## 8. 검증 범위

입력 허용·거부의 경계값과 한 번의 코드 생성 요청을 확인한다. 생성된 코드의 실행 가능성이나 정답률은 이번 최소 기능의 완료 조건에 포함하지 않는다. 이 문서는 구현 요구사항이며, 현재 Python 환경에는 PyTorch가 설치되어 있지 않아 실제 모델 추론은 아직 검증되지 않았다.
