# 03. CodeBot BPE 토크나이저 학습

[← DAY2 목차](<README.md>) · [원본 노트북](<03_CodeBot BPE 토크나이저 학습.ipynb>)

코드 말뭉치에서 BPE 병합 규칙을 학습해 CodeBot의 토크나이저를 준비했다.

## 핵심 개념

CodeBot은 텍스트 원문 대신 토큰 ID를 입력으로 사용한다. BPE 규칙을 학습하는 단계와 언어 모델의 가중치를 학습하는 단계는 별개이며, 모델을 다시 읽을 때도 학습 당시의 규칙이 필요하다.

기본 바이트 256개에서 시작해 목표 어휘 크기까지 병합한다. merge rule 파일은 이후 인코딩·디코딩에 사용할 토큰 체계를 고정하는 역할을 한다.

병합 규칙은 단순한 압축 사전이면서 모델의 입력 어휘를 정의하는 파일이다. 같은 어휘 크기 1,000으로 다시 학습해도 각 ID가 가리키는 조각이 달라질 수 있다. 따라서 텍스트, 병합 규칙, 토큰 바이너리, 모델 가중치는 한 묶음으로 관리해야 한다. 규칙을 바꾸었다면 기존 바이너리를 그대로 읽기 전에 다시 인코딩할 필요가 있는지 확인한다.

## 실습 흐름

같은 DAY의 `CodeBot/tiny_codes.txt`를 읽고 `train_bpe`에 목표 어휘 크기 1,000을 전달한다. 학습한 규칙은 `CodeBot/merge_rules.pkl`에 저장하고 다음 사전학습 노트북에서 읽는다.

## 실행 결과

저장 출력에는 744개의 병합 규칙을 저장했다고 나온다. 초기 바이트 256개와 합쳐 어휘 크기 1,000에 해당한다. 규칙 생성 결과이며 코드 생성 품질을 나타내는 지표는 아니다.

## 필요한 파일

`tiny_codes.txt`, `tokenizer.py`, `merge_rules.pkl`은 같은 DAY의 `CodeBot/` 폴더에 포함돼 있다.

## 다시 볼 것

토크나이저를 다시 학습해 규칙이 바뀌면 기존 토큰 바이너리와 모델 가중치가 같은 ID 의미를 공유하는지 확인한다.
