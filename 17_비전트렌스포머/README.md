# 비전 트랜스포머 학습 저장소

[← 저장소 목차](<../README.md>)

Fashion-MNIST를 ViT, Swin Transformer, CvT로 분류하는 실습이다. 동일한 데이터 처리 흐름에서 모델 구조와 평가 결과를 비교한다.

## 과정 목차

| DAY | 주요 주제 | 학습노트 |
|---|---|---|
| DAY1 | ViT 패치 임베딩과 Fashion-MNIST 분류 | [DAY1 열기](<DAY1_261001/README.md>) |
| DAY2 | Swin Transformer·CvT 분류와 비교 | [DAY2 열기](<DAY2_261002/README.md>) |

## 실행 환경

이 과정 폴더의 가상환경을 VS Code 노트북 커널로 선택한다. [requirements.txt](<requirements.txt>)와 [requirements-gpu.txt](<requirements-gpu.txt>)에 환경별 패키지 목록이 있다. 두 파일은 기존 수업 환경 기록이며 다른 과정의 환경과 무조건 합쳐 설치하지 않는다.

노트북 첫 셀에서 실행 DAY를 찾는다. 데이터는 과정 공용 `datasets/`, 모델은 공용 `models/`에 저장한다. 패키지 버전에 따라 Trainer 인자 이름이 달라질 수 있으므로 원래 실습 환경을 먼저 확인한다.

## 결과를 볼 때

ViT와 Swin에는 저장된 최종 F1이 있고 CvT에는 학습 완료 출력이 없다. 학습 표본 10,000장과 평가 표본 1,000장을 사용하며, 평가 표본은 최적 체크포인트 선택에도 사용한다. 최종 성능 비교를 하려면 별도의 테스트 표본이 필요하다.

## 문서 활용법

- `.ipynb`: 실행용 노트북
- 동명 `.md`: 개념, 실습 흐름, 저장된 결과와 다시 볼 내용을 정리한 학습노트
- DAY별 `README.md`: 실습 순서와 필요한 파일 안내

학습노트의 수치는 노트북에 저장된 이전 실행 기록을 기준으로 적었다. 정리 과정에서 장시간 학습이나 외부 API 평가는 다시 실행하지 않았다.
