# 03. CvT Fashion-MNIST 분류

[← DAY2 목차](<README.md>) · [원본 노트북](<03_CvT Fashion-MNIST 분류.ipynb>)

합성곱 구조를 포함한 CvT를 Fashion-MNIST 분류에 적용하는 코드다. 앞의 ViT·Swin과 데이터 처리 및 평가 흐름을 맞춰 비교할 수 있게 구성했다.

## 핵심 개념

CvT는 토큰 임베딩과 attention 투영에 합성곱을 사용해 이미지의 국소 구조를 반영한다. 합성곱과 attention을 결합한다는 점이 중심이며, 단순히 모델 이름만 바꾼 CNN은 아니다.

사전학습 모델을 가져올 때 분류층의 출력 크기는 현재 데이터에 맞춰 바꾼다. 크기가 다른 분류층을 새로 만드는 설정은 기존 본체의 가중치를 활용하면서 새 과제를 학습하기 위한 것이다.

## 실습 흐름

ViT·Swin과 같은 방식으로 클래스별 표본을 선택하고 `microsoft/cvt-21`의 입력 설정을 읽는다. 흑백을 3채널로 바꾸어 정규화한 뒤 Trainer와 macro F1 평가, 혼동행렬 코드를 구성한다.

## 실행 결과

저장본에는 일부 환경 경고만 있고 학습 완료·최종 평가 출력은 없다. 따라서 ViT·Swin과 비교할 CvT의 F1 수치는 아직 제시하지 않는다.

## 필요한 파일

데이터는 과정 루트의 `datasets/`, 학습 결과는 `models/cvt-21/`를 사용한다. 이미지와 모델은 처음 실행할 때 내려받는다.

## 다시 볼 것

세 모델의 실제 학습 완료 여부를 먼저 구분한다. 사전학습 모델별 입력 설정과 파라미터 수가 달라 완전히 같은 실험 조건은 아니라는 점도 함께 본다.
