# 채용 정보 스크래퍼

[← 저장소 목차](<../README.md>)

검색어로 채용 정보를 수집하고 화면에서 확인하거나 CSV 파일로 내려받는 Flask 실습.

## 파일

| 파일 | 내용 |
|---|---|
| `app.py` | Flask 라우팅과 검색 결과 캐시 |
| `scrapper.py` | 채용 정보 수집 |
| `file.py` | 검색 결과 CSV 저장 |
| `templates/` | 검색 화면과 결과 화면 |

```bash
pip install -r requirements.txt
python app.py
```
