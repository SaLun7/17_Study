# 20. PCA 차원 축소

[← DAY7 목차](<README.md>) · [원본 노트북](<20_PCA 차원 축소.ipynb>)

PCA로 고차원 데이터를 분산이 큰 직교 축으로 변환하고 Iris와 유방암 데이터를 저차원에서 시각화한다.

## 핵심 개념

### 주성분

원 피처의 선형결합으로 만든 서로 직교하는 새 축이다.

### 설명분산비

각 축이 전체 변동 중 얼마나 설명하는지 나타낸다.

### 표준화

단위가 큰 피처가 분산을 지배하지 않도록 스케일을 맞춘다.

PCA는 정답 라벨을 보지 않으므로 클래스가 잘 나뉘는 방향과 분산이 큰 방향이 항상 같지는 않다. 2차원 그림이 겹쳐 보여도 원래 공간에서 분류가 어렵다는 뜻은 아니다. 표준화 기준과 남긴 주성분 수를 함께 기록해야 다른 실행의 그림과 비교할 수 있다.

## 실습 흐름

Iris 피처를 표준화한 뒤 PCA로 두 개의 주성분을 만들고 클래스별 분포를 평면에 표시했다. 각 주성분의 설명분산비를 확인해 두 축이 원 데이터의 변동을 얼마나 남기는지 계산했다. 유방암 데이터에도 같은 과정을 적용해 축소 전 피처와 분류 성능의 변화를 비교했다.

### 사용한 함수

| 함수·클래스 | 역할 |
|---|---|
| `load_iris` | Iris 데이터셋 불러오기 |
| `read_excel` | Excel 파일을 DataFrame으로 읽기 |
| `cross_val_score` | 교차검증 점수 계산 |
| `StandardScaler` | 평균 0, 표준편차 1로 표준화 |
| `RandomForestClassifier` | 여러 무작위 트리를 결합한 분류 모델 |
| `PCA` | 분산을 보존하는 비지도 차원축소 |

## 실행 결과

2차원 그림에서 클래스가 잘 나뉘어 보여도 축소 과정에서 손실된 정보가 있다. 모델 전처리로 사용할 때는 파이프라인 안에서 교차검증한다.

## 다시 볼 것

- PCA 전에 피처 단위와 분산 차이를 확인한다.
- 설명분산비가 높아도 정답 클래스를 잘 나눈다는 뜻은 아니다.
- 주성분의 부호와 축 방향은 실행이나 구현에 따라 뒤집힐 수 있다.
