# 16. 로지스틱 회귀와 회귀트리

[← DAY5 목차](<README.md>) · [원본 노트북](<16_로지스틱 회귀와 회귀트리.ipynb>)

로지스틱 회귀 분류와 트리 기반 회귀를 한 노트북에서 비교하며 선형 경계와 비선형 회귀의 차이를 확인한다.

## 핵심 개념

### 로지스틱 회귀

이름과 달리 분류 모델이며 양성 확률을 로짓의 선형결합으로 표현한다.

### 회귀트리

입력 공간을 구간으로 나누고 각 구간의 평균값을 예측한다.

### 깊이

깊은 트리는 계단형 경계를 세밀하게 만들지만 과적합 위험이 커진다.

로지스틱 회귀는 분류 경계를 확률로 해석하지만 입력의 비선형 관계를 자동으로 표현하지는 못한다. 회귀트리는 값이 구간별로 일정하게 나오는 구조라 학습 범위를 벗어난 값을 외삽하는 데 약하다. 두 모델의 출력 형식과 평가 지표부터 구분한다.

## 실습 흐름

유방암 데이터에서는 로지스틱 회귀의 solver와 규제 강도 `C`를 바꿔 분류 성능을 비교했다. California Housing 데이터에서는 선형회귀와 회귀트리를 교차검증 RMSE로 평가했다. 하나의 입력 축에서 깊이가 다른 회귀트리의 계단형 예측을 그려 선형 모델과 비선형 모델의 차이를 확인했다.

### 사용한 함수

| 함수·클래스 | 역할 |
|---|---|
| `load_breast_cancer` | 유방암 분류 데이터셋 불러오기 |
| `fetch_california_housing` | California Housing 회귀 데이터 불러오기 |
| `train_test_split` | 학습용과 평가용 데이터 분리 |
| `cross_val_score` | 교차검증 점수 계산 |
| `GridSearchCV` | 파라미터 조합을 교차검증으로 탐색 |
| `StandardScaler` | 평균 0, 표준편차 1로 표준화 |
| `LogisticRegression` | 확률 기반 선형 분류 모델 |
| `RandomForestRegressor` | 여러 무작위 트리를 결합한 회귀 모델 |
| `XGBRegressor` | XGBoost 회귀 모델 |
| `LGBMRegressor` | LightGBM 회귀 모델 |
| `LinearRegression` | 일반 선형회귀 모델 |
| `accuracy_score` | 분류 정확도 계산 |

## 실행 결과

분류 정확도/AUC와 회귀 RMSE는 서로 다른 문제의 지표이므로 직접 비교하지 않는다. 회귀 모델 비교에서는 동일한 교차검증 분할과 오차 정의를 사용한다.

## 다시 볼 것

- 로지스틱 회귀의 `C`는 값이 작을수록 규제가 강해진다.
- 분류 정확도와 회귀 RMSE를 서로 같은 지표처럼 비교하지 않는다.
- 회귀트리의 깊이를 늘렸을 때 검증 오차가 실제로 줄어드는지 확인한다.
