# 17. 자전거 대여량 예측

[← DAY5 목차](<README.md>) · [원본 노트북](<17_자전거 대여량 예측.ipynb>)

날짜·시간·날씨 정보를 이용해 자전거 대여량을 예측하고 전처리와 여러 회귀 모델의 성능을 비교한다.

## 핵심 개념

### 시간 피처

시간·요일·계절은 대여 패턴의 주기성을 표현한다.

### 로그 목표

대여량의 오른쪽 꼬리를 줄여 큰 값의 영향과 이분산성을 완화한다.

### 역변환

log1p로 학습한 예측은 expm1으로 실제 대여량 단위에 복원한다.

대여량은 시간대와 요일에 따라 달라지므로 무작위 분할보다 미래를 예측하는 상황에 맞는 시간 순서 검증이 중요할 수 있다. 학습 목표를 로그로 바꿨다면 예측을 원 단위로 되돌린 뒤 오차를 계산해야 운영상 차이가 읽힌다. 누출 가능성이 있는 사후 집계 열도 확인한다.

## 실습 흐름

문자열 날짜에서 연, 월, 일과 시간 피처를 만들고 불필요해진 원본 날짜 열을 정리했다. 대여량 분포의 긴 꼬리를 확인해 `log1p`로 변환한 뒤 선형회귀, 랜덤 포레스트와 부스팅 회귀를 같은 분할에서 비교했다. 예측은 `expm1`으로 실제 대여량 단위에 되돌려 MAE, RMSE와 R²를 계산했다.

### 사용한 함수

| 함수·클래스 | 역할 |
|---|---|
| `read_csv` | CSV 파일을 DataFrame으로 읽기 |
| `train_test_split` | 학습용과 평가용 데이터 분리 |
| `RandomForestRegressor` | 여러 무작위 트리를 결합한 회귀 모델 |
| `XGBRegressor` | XGBoost 회귀 모델 |
| `LinearRegression` | 일반 선형회귀 모델 |
| `mean_squared_error` | 평균제곱오차 계산 |
| `mean_absolute_error` | 평균절대오차 계산 |
| `r2_score` | 평균 기준선 대비 설명력 계산 |

## 실행 결과

모델 개선은 R2 상승뿐 아니라 MAE와 RMSE 감소가 함께 나타나는지 확인한다. 시간 순서가 중요한 데이터에서는 무작위 분할 외에 시간 기반 검증도 고려한다.
