# 17. 자전거 대여량 예측

날짜·시간·날씨 정보를 이용해 자전거 대여량을 예측하고 전처리와 여러 회귀 모델의 성능을 비교한다.

[← DAY5 목차](<README.md>) · [원본 노트북](<17_자전거 대여량 예측.ipynb>)

## 실습 내용

- datetime에서 연·월·일·시간 피처를 만든다.
- 목표값의 긴 꼬리를 로그 변환한다.
- 선형·트리·부스팅 회귀를 MAE/RMSE/R2로 비교한다.
- 예측값을 원 단위로 복원한다.

**데이터**  
Bike Sharing 데이터: datetime, 계절, 날씨, 온도, 습도, 풍속과 count

## 핵심 메모

### 시간 피처

시간·요일·계절은 대여 패턴의 주기성을 표현한다.

### 로그 목표

대여량의 오른쪽 꼬리를 줄여 큰 값의 영향과 이분산성을 완화한다.

### 역변환

log1p로 학습한 예측은 expm1으로 실제 대여량 단위에 복원한다.

## 코드

코드는 길어서 중요한 셀만 접어 두었다. 전체 실행 과정은 원본 노트북에서 확인한다.

<details>
<summary>코드 셀 14 보기</summary>

```python
from sklearn.metrics import mean_squared_error, mean_absolute_error, r2_score
import numpy as np

def print_score(valid_x, valid_y):
    pred = model.predict(valid_x)
    
    pred = np.expm1(pred)
    valid_y_orig = np.expm1(valid_y)

    print(f"MAE: {mean_absolute_error(valid_y_orig, pred)}")
    print(f"RMSE: {np.sqrt(mean_squared_error(valid_y_orig, pred))}")
    print(f"R2_SCORE: {r2_score(valid_y_orig, pred)}")

print_score(valid_x, valid_y)
```

## 실습 흐름

문자열 날짜에서 연, 월, 일과 시간 피처를 만들고 불필요해진 원본 날짜 열을 정리했다. 대여량 분포의 긴 꼬리를 확인해 `log1p`로 변환한 뒤 선형회귀, 랜덤 포레스트와 부스팅 회귀를 같은 분할에서 비교했다. 예측은 `expm1`으로 실제 대여량 단위에 되돌려 MAE, RMSE와 R²를 계산했다.

## 결과 메모
