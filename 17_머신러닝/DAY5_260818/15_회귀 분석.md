# 15. 회귀 분석

[← DAY5 목차](<README.md>) · [원본 노트북](<15_회귀 분석.ipynb>)

선형회귀, 다항회귀, Ridge와 Lasso를 통해 연속값 예측과 규제의 효과를 이해한다.

## 핵심 개념

### 잔차

실제값과 예측값의 차이로 모델이 놓친 구조를 보여준다.

### RMSE

큰 오차에 더 큰 벌점을 주며 목표변수와 같은 단위로 해석한다.

### Ridge/Lasso

계수를 제한해 복잡도를 낮추며 Lasso는 일부 계수를 0으로 만들 수 있다.

잔차가 특정 구간에서 계속 한쪽으로 치우치면 모델이 그 구간의 관계를 충분히 표현하지 못했을 수 있다. RMSE와 MAE를 같이 보면 드문 큰 오차가 평균 성능을 얼마나 흔드는지 살펴볼 수 있다. 규제 전에는 피처 단위를 맞춰 계수 크기가 단위 차이만 반영하지 않도록 한다.

## 실습 흐름

합성 데이터로 선형회귀의 계수와 잔차를 확인한 뒤 다항식 차수를 높여 예측 곡선이 어떻게 변하는지 비교했다. 이어서 Ridge와 Lasso의 규제 강도를 여러 값으로 교차검증하고 RMSE가 가장 낮은 구간을 찾았다. 분포가 한쪽으로 긴 피처와 목표값에는 로그 변환을 적용해 결과 변화를 살펴봤다.

### 사용한 함수

| 함수·클래스 | 역할 |
|---|---|
| `fetch_california_housing` | California Housing 회귀 데이터 불러오기 |
| `train_test_split` | 학습용과 평가용 데이터 분리 |
| `cross_val_score` | 교차검증 점수 계산 |
| `StandardScaler` | 평균 0, 표준편차 1로 표준화 |
| `LinearRegression` | 일반 선형회귀 모델 |
| `Ridge` | L2 규제 선형회귀 모델 |
| `Lasso` | L1 규제 선형회귀 모델 |
| `mean_squared_error` | 평균제곱오차 계산 |
| `r2_score` | 평균 기준선 대비 설명력 계산 |

## 필요한 파일

합성 회귀 데이터와 주택 관련 회귀 데이터

데이터를 불러오는 셀부터 실행한다. 별도의 로컬 입력 파일을 지정하지 않는다.

## 다시 볼 것

- 훈련 RMSE와 검증 RMSE가 함께 낮아지는지 확인한다.
- 다항 차수를 높일수록 훈련 오차는 줄어도 검증 오차는 커질 수 있다.
- 규제 전에는 피처 스케일 차이가 계수에 미치는 영향을 확인한다.
