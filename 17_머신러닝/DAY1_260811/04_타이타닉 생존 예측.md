# 04. 타이타닉 생존 예측

[← DAY1 목차](<README.md>) · [원본 노트북](<04_타이타닉 생존 예측.ipynb>)

타이타닉 승객 데이터의 결측치와 범주형 변수를 처리하고 여러 분류 모델로 생존 여부를 예측한다.

## 핵심 개념

### 결측치 처리

Age는 대표값, Cabin과 Embarked는 별도 범주 등 열의 의미에 맞는 전략이 필요하다.

### 데이터 누수

검증·테스트 정보를 이용해 대체값이나 범주 사전을 만들면 실제 성능보다 높게 보일 수 있다.

### 모델 비교

전처리와 데이터 분할을 고정해야 모델 점수 차이가 의미를 가진다.

탑승객의 나이·성별·요금은 같은 표에 있어도 결측 방식과 의미가 다르다. 누락된 나이를 하나의 평균으로 채울 때는 어떤 집단의 평균인지도 결과에 영향을 준다. 전처리 방법을 정한 뒤에는 테스트 자료에 동일한 규칙을 적용해야 한다.

## 실습 흐름

승객 정보의 결측값과 문자열 범주를 확인하고 Age, Cabin, Embarked 등을 모델이 읽을 수 있는 형태로 정리했다. 전처리를 하나의 함수로 묶어 같은 규칙을 반복 적용한 뒤 여러 분류 모델을 학습하고 교차검증 점수를 비교했다. 생존 여부와 관련 있어 보이는 성별, 객실 등급 등의 분포도 함께 살펴봤다.

### 사용한 함수

| 함수·클래스 | 역할 |
|---|---|
| `read_csv` | CSV 파일을 DataFrame으로 읽기 |
| `train_test_split` | 학습용과 평가용 데이터 분리 |
| `OneHotEncoder` | 범주별 0/1 열 생성 |
| `OrdinalEncoder` | 순서형 범주를 정수로 변환 |
| `Binarizer` | 지정 임계값으로 연속값을 0/1 변환 |
| `DecisionTreeClassifier` | 결정트리 분류 모델 |
| `LogisticRegression` | 확률 기반 선형 분류 모델 |
| `RandomForestClassifier` | 여러 무작위 트리를 결합한 분류 모델 |
| `accuracy_score` | 분류 정확도 계산 |

## 실행 결과

세 모델의 예측 분포가 다르면 어떤 승객에서 판단이 갈리는지 확인할 수 있다. 단순 생존자 수보다 검증 정확도와 클래스별 오류를 우선 해석한다.

## 필요한 파일

Titanic train/test CSV: Survived가 목표이며 Age, Sex, Pclass, Fare, Embarked 등을 입력으로 사용

같은 DAY의 `data/train.csv`, `data/test.csv`가 필요하다. 현재 저장소에는 없어 별도로 준비한다.

## 다시 볼 것

- 결측값을 채울 때 전체 데이터의 정답 정보가 섞이지 않게 한다.
- 이름이나 객실 번호처럼 가공할 수 있는 문자열을 바로 버릴지 검토한다.
- 대회 점수뿐 아니라 어떤 승객 집단에서 오류가 나는지도 확인한다.
