# 01. 머신러닝 기본 흐름 - 붓꽃 분류

[← DAY1 목차](<README.md>) · [원본 노트북](<01_머신러닝 기본 흐름 - 붓꽃 분류.ipynb>)

Iris 데이터를 이용해 입력과 정답을 준비하고, 결정트리를 학습한 뒤 새로운 붓꽃의 품종을 예측한다.

## 핵심 개념

### 피처와 레이블

피처는 모델이 사용하는 입력 정보이고 레이블은 모델이 맞혀야 하는 정답이다.

### 학습과 테스트

모델이 보지 못한 데이터로 평가해야 실제 일반화 성능을 추정할 수 있다.

### 결정트리

입력값에 조건을 반복 적용해 공간을 나누고 최종 클래스를 결정한다.

여기서 정확도는 모델이 처음 보는 테스트 자료에 대해 계산한 값이다. 학습 자료의 점수가 높아도 테스트 점수가 다르면 나무가 학습 사례의 세부 조건을 외웠을 가능성을 봐야 한다. 데이터 분할의 기준을 먼저 고정해야 다음 모델과 비교할 수 있다.

## 실습 흐름

Iris 데이터를 DataFrame으로 살펴보고 네 개의 측정값을 입력 `X`, 품종을 정답 `y`로 나눴다. 학습용과 테스트용 데이터를 분리한 뒤 결정트리를 학습하고, 테스트 예측값을 실제 품종과 비교해 정확도를 계산했다. 한 번의 결과가 전체 성능을 대표하지 않는다는 점은 다음 교차검증 실습으로 이어진다.

### 사용한 함수

| 함수·클래스 | 역할 |
|---|---|
| `load_iris` | Iris 데이터셋 불러오기 |
| `train_test_split` | 학습용과 평가용 데이터 분리 |
| `DecisionTreeClassifier` | 결정트리 분류 모델 |
| `accuracy_score` | 분류 정확도 계산 |

## 실행 결과

예측값과 정확도는 모델 학습이 정상적으로 수행됐는지 확인하는 기준이다. 정확도는 클래스별 오류를 보여주지 않으므로 다음 단계에서는 혼동행렬과 함께 보는 것이 좋다.

## 필요한 파일

Iris 데이터셋: 꽃받침과 꽃잎의 길이·너비 4개 피처, setosa·versicolor·virginica 3개 클래스

데이터를 불러오는 셀부터 실행한다. 별도의 로컬 입력 파일을 지정하지 않는다.

## 다시 볼 것

- 입력과 정답의 행 개수가 같은지 먼저 확인한다.
- 테스트 데이터는 모델을 학습하거나 기준을 정할 때 사용하지 않는다.
- 정확도만으로 어떤 품종을 자주 틀리는지는 알 수 없으므로 혼동행렬도 함께 본다.
- 같은 분할을 재현하려면 `random_state`도 함께 기록한다.
