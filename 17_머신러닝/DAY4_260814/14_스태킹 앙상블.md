# 14. 스태킹 앙상블

[← DAY4 목차](<README.md>) · [원본 노트북](<14_스태킹 앙상블.ipynb>)

여러 기반 분류기의 예측을 새로운 특성으로 만들고 메타 모델이 최종 예측을 학습하도록 구성한다.

## 핵심 개념

### 기반 모델

원본 피처에서 서로 다른 관점의 예측을 생성한다.

### 메타 피처

기반 모델의 예측값을 열로 결합한 새로운 학습 데이터다.

### OOF 예측

기반 모델이 직접 학습하지 않은 fold의 예측으로 메타 모델의 누수를 막는다.

메타 모델이 학습할 예측값은 기반 모델이 보지 못한 자료에 대해 만든 값이어야 한다. 학습 자료를 그대로 다시 예측해 메타 피처를 만들면 점수가 과장된다. 최종 테스트를 예측할 때는 fold별 기반 모델 결과를 어떻게 합칠지도 학습 때와 일관되게 정한다.

## 실습 흐름

여러 기반 모델을 같은 학습 데이터로 학습하고 각 예측값을 새로운 피처처럼 모았다. 단순 방식의 결과를 확인한 뒤 K-Fold의 검증 구간에서 만든 OOF 예측으로 메타 모델용 학습 데이터를 구성했다. 기반 모델의 테스트 예측은 fold별 결과를 평균해 메타 모델 입력으로 사용했다.

### 사용한 함수

| 함수·클래스 | 역할 |
|---|---|
| `load_breast_cancer` | 유방암 분류 데이터셋 불러오기 |
| `train_test_split` | 학습용과 평가용 데이터 분리 |
| `KFold` | K개의 교차검증 분할 생성 |
| `DecisionTreeClassifier` | 결정트리 분류 모델 |
| `LogisticRegression` | 확률 기반 선형 분류 모델 |
| `RandomForestClassifier` | 여러 무작위 트리를 결합한 분류 모델 |
| `accuracy_score` | 분류 정확도 계산 |
| `mean_absolute_error` | 평균절대오차 계산 |

## 실행 결과

스태킹이 단일 모델보다 복잡한 만큼 개선폭이 계산량과 유지보수 비용을 정당화하는지 확인한다. 기반 모델의 다양성이 낮으면 개선이 제한적이다.

## 필요한 파일

유방암 분류 데이터와 여러 scikit-learn 분류기

데이터를 불러오는 셀부터 실행한다. 별도의 로컬 입력 파일을 지정하지 않는다.

## 다시 볼 것

- 메타 모델이 기반 모델의 훈련 데이터 예측을 그대로 보면 누수가 생긴다.
- 기반 모델 사이의 오류가 다를수록 스태킹이 도움 될 가능성이 크다.
- 단일 모델보다 개선 폭이 작은 경우 복잡도 증가가 필요한지 다시 판단한다.
