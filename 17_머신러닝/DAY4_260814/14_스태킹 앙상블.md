### 메타 피처

기반 모델의 예측값을 열로 결합한 새로운 학습 데이터다.

### OOF 예측

기반 모델이 직접 학습하지 않은 fold의 예측으로 메타 모델의 누수를 막는다.

```python
from sklearn.model_selection import KFold
from sklearn.metrics import mean_absolute_error

def get_stacking_base_datasets(model, X_train_n, y_train_n, X_test_n, n_folds ):

    kf = KFold(n_splits=n_folds, shuffle=False)

    train_fold_pred = np.zeros((X_train_n.shape[0] ,1 ))
    test_pred = np.zeros((X_test_n.shape[0],n_folds))
    print(model.__class__.__name__ , ' model 시작 ')
    
    for folder_counter , (train_index, valid_index) in enumerate(kf.split(X_train_n)):

        print('\t 폴드 세트: ',folder_counter,' 시작 ')
        X_tr = X_train_n[train_index] 
        y_tr = y_train_n[train_index] 
        X_te = X_train_n[valid_index]  
        
        model.fit(X_tr , y_tr)       

        train_fold_pred[valid_index, :] = model.predict(X_te).reshape(-1,1)
        test_pred[:, folder_counter] = model.predict(X_test_n)
            
    test_pred_mean = np.mean(test_pred, axis=1).reshape(-1,1)    
    
    return train_fold_pred , test_pred_mean
```

## 실습 흐름

여러 기반 모델을 같은 학습 데이터로 학습하고 각 예측값을 새로운 피처처럼 모았다. 단순 방식의 결과를 확인한 뒤 K-Fold의 검증 구간에서 만든 OOF 예측으로 메타 모델용 학습 데이터를 구성했다. 기반 모델의 테스트 예측은 fold별 결과를 평균해 메타 모델 입력으로 사용했다.

## 결과 메모

스태킹이 단일 모델보다 복잡한 만큼 개선폭이 계산량과 유지보수 비용을 정당화하는지 확인한다. 기반 모델의 다양성이 낮으면 개선이 제한적이다.

## 사용한 함수

| 함수·클래스 | 역할 |
|---|---|
| `load_breast_cancer` | 유방암 분류 데이터셋 불러오기 |

| `RandomForestClassifier` | 여러 무작위 트리를 결합한 분류 모델 |
| `accuracy_score` | 분류 정확도 계산 |
| `mean_absolute_error` | 평균절대오차 계산 |

## 다시 볼 것

- 메타 모델이 기반 모델의 훈련 데이터 예측을 그대로 보면 누수가 생긴다.
- 기반 모델 사이의 오류가 다를수록 스태킹이 도움 될 가능성이 크다.
- 단일 모델보다 개선 폭이 작은 경우 복잡도 증가가 필요한지 다시 판단한다.

## 정리

- 학습 데이터 자체에 대한 기반 모델 예측을 메타 입력으로 쓰지 않는다.
- 기반 모델마다 같은 fold를 사용한다.
- 최종 테스트 세트는 전체 스태킹 구조가 완성된 뒤 한 번만 평가한다.
