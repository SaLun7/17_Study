# 13. 신용카드 사기 탐지

[← DAY4 목차](<README.md>) · [원본 노트북](<13_신용카드 사기 탐지.ipynb>)

극심한 클래스 불균형을 가진 거래 데이터에서 로지스틱 회귀와 LightGBM을 비교하고 스케일링과 이상치 처리 효과를 확인한다.

## 핵심 개념

### 불균형 착시

정상 거래만 예측해도 정확도가 매우 높게 나올 수 있다.

### 재현율

실제 사기를 얼마나 놓치지 않고 찾았는지 나타낸다.

### 이상치

사기 신호일 수도 있으므로 업무 의미 없이 무조건 제거하면 안 된다.

사기 탐지에서는 놓친 사기와 정상 거래를 잘못 막은 경우의 비용이 다르다. SMOTE 같은 재표본화는 학습 폴드에만 적용해야 검증 표본과 합성 표본이 서로 영향을 주지 않는다. 이상치를 무조건 제거하면 오히려 드문 사기 신호를 지울 수 있다.

## 실습 흐름

사기 비율을 유지해 데이터를 분할하고 로지스틱 회귀와 LightGBM으로 기준 결과를 만들었다. 거래 금액을 표준화하거나 로그 변환한 뒤 결과가 어떻게 달라지는지 비교했고, 주요 피처의 이상치를 제거한 실험도 따로 진행했다. 각 단계마다 혼동행렬과 정밀도, 재현율, F1, AUC를 같은 함수로 계산했다.

### 사용한 함수

| 함수·클래스 | 역할 |
|---|---|
| `read_csv` | CSV 파일을 DataFrame으로 읽기 |
| `train_test_split` | 학습용과 평가용 데이터 분리 |
| `StandardScaler` | 평균 0, 표준편차 1로 표준화 |
| `LogisticRegression` | 확률 기반 선형 분류 모델 |
| `LGBMClassifier` | LightGBM 분류 모델 |
| `accuracy_score` | 분류 정확도 계산 |
| `confusion_matrix` | TN·FP·FN·TP 혼동행렬 계산 |
| `precision_score` | 정밀도 계산 |
| `recall_score` | 재현율 계산 |
| `f1_score` | 정밀도와 재현율의 조화평균 계산 |
| `roc_auc_score` | 확률 순위 기반 ROC-AUC 계산 |
