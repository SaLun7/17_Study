# 12. 고객 만족도 예측

[← DAY4 목차](<README.md>) · [원본 노트북](<12_고객 만족도 예측.ipynb>)

산탄데르 고객 데이터를 전처리하고 XGBoost와 LightGBM을 ROC-AUC 기준으로 최적화한다.

## 핵심 개념

### 희소 양성

불만족 고객이 적으면 정확도보다 양성 순위와 재현 성능이 중요하다.

### ROC-AUC

여러 임계값에서 불만족 고객을 상위에 배치하는 능력을 평가한다.

### 익명 피처

이름으로 의미를 알 수 없으므로 분포·결측·상수 열을 통계적으로 점검한다.

불만족 고객이 드물면 양성을 거의 찾지 못해도 전체 정확도는 높을 수 있다. 순위 지표가 좋아도 실제 연락 대상을 정할 때는 상위 몇 명을 고를지 임계값이 필요하다. 고객군별 누락 패턴과 서비스 시점 이후에만 알 수 있는 열이 들어갔는지도 살펴본다.

## 실습 흐름

고객 만족 여부의 비율과 피처 분포를 확인하고 식별자처럼 예측에 도움이 되지 않는 열을 분리했다. 불균형한 정답 비율을 유지해 학습·평가 데이터를 나눈 뒤 부스팅 모델을 학습했다. 중요도가 낮은 피처를 정리한 경우와 전체 피처를 사용한 경우의 AUC를 비교했다.

### 사용한 함수

| 함수·클래스 | 역할 |
|---|---|
| `read_csv` | CSV 파일을 DataFrame으로 읽기 |
| `train_test_split` | 학습용과 평가용 데이터 분리 |
| `KFold` | K개의 교차검증 분할 생성 |
| `XGBClassifier` | XGBoost 분류 모델 |
| `LGBMClassifier` | LightGBM 분류 모델 |
| `roc_auc_score` | 확률 순위 기반 ROC-AUC 계산 |

## 실행 결과

모델 간 AUC 차이가 작다면 fold별 변동과 운영 임계값에서의 정밀도·재현율을 함께 본다. 파라미터 탐색보다 누수 없는 검증 설계가 우선이다.

- 고객 ID 같은 식별자가 우연한 패턴으로 사용되지 않는지 확인한다.
- 불균형 분류에서는 정확도보다 ROC-AUC와 재현율을 함께 본다.
- 피처를 줄일 때는 같은 교차검증 조건에서 성능과 시간을 비교한다.
