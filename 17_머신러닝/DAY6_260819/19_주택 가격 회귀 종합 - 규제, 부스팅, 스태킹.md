# 19. 주택 가격 회귀 종합 - 규제, 부스팅, 스태킹

[← DAY6 목차](<README.md>) · [원본 노트북](<19_주택 가격 회귀 종합 - 규제, 부스팅, 스태킹.ipynb>)

주택 가격 데이터에 선형 규제, 왜도 변환, 이상치 제거, 부스팅, 예측 혼합과 스태킹을 단계적으로 적용한다.

## 핵심 개념

### 규제

다중공선성과 과적합을 완화하며 alpha를 교차검증으로 선택한다.

### 왜도 변환

긴 꼬리 수치 피처를 log1p로 변환해 선형 모델의 가정을 개선한다.

### 모델 혼합

오류 패턴이 다른 예측을 가중 평균하면 분산을 줄일 수 있다.

### 스태킹

OOF 기반 예측을 메타 모델 입력으로 사용한다.

규제 선형 모델과 트리 부스팅은 잘 맞히는 사례와 크게 틀리는 사례가 다를 수 있다. 가중 평균의 이득은 개별 점수보다 두 모델의 잔차가 얼마나 다른지에서 나온다. 스태킹도 OOF 예측을 사용하지 않으면 검증 결과가 쉽게 부풀려진다.

## 실습 흐름

선형회귀를 기준으로 Ridge와 Lasso의 규제 강도를 교차검증하고, 수치 피처의 왜도와 주거 면적 이상치를 정리했다. 같은 데이터에서 XGBoost와 LightGBM을 학습한 뒤 Ridge·Lasso 예측을 가중 평균했다. 마지막에는 각 기반 모델의 OOF 예측을 만들어 Lasso 메타 모델에 전달하는 스태킹을 구성했다.

### 사용한 함수

| 함수·클래스 | 역할 |
|---|---|
| `read_csv` | CSV 파일을 DataFrame으로 읽기 |
| `train_test_split` | 학습용과 평가용 데이터 분리 |
| `KFold` | K개의 교차검증 분할 생성 |
| `cross_val_score` | 교차검증 점수 계산 |
| `GridSearchCV` | 파라미터 조합을 교차검증으로 탐색 |
| `XGBRegressor` | XGBoost 회귀 모델 |
| `LGBMRegressor` | LightGBM 회귀 모델 |
| `LinearRegression` | 일반 선형회귀 모델 |
| `Ridge` | L2 규제 선형회귀 모델 |
| `Lasso` | L1 규제 선형회귀 모델 |
| `mean_squared_error` | 평균제곱오차 계산 |
| `mean_absolute_error` | 평균절대오차 계산 |

## 실행 결과

각 전처리와 앙상블 단계에서 CV RMSE가 실제로 감소하는지 기록해야 복잡도 증가의 가치를 판단할 수 있다. 미실행 셀은 결과로 간주하지 않는다.
