# 08. 앙상블 학습

[← DAY3 목차](<README.md>) · [원본 노트북](<08_앙상블 학습.ipynb>)

Voting, Random Forest, Gradient Boosting을 이용해 여러 모델을 결합하는 방식을 비교한다.

## 핵심 개념

### Voting

서로 다른 모델의 클래스 또는 확률을 결합한다.

### Random Forest

여러 부트스트랩 표본과 무작위 피처로 독립 트리를 학습해 평균한다.

### Gradient Boosting

이전 모델의 오류를 다음 모델이 순차적으로 보정한다.

Voting과 Random Forest는 여러 예측을 모으지만 모델을 만드는 방식이 다르다. Voting은 이미 학습한 서로 다른 모델을 결합하고, Random Forest는 자료와 피처를 달리해 여러 트리를 만든다. Boosting은 앞선 오류를 순서대로 보완하므로 트리 수와 학습률을 함께 조절한다.

## 실습 흐름

서로 다른 분류기의 결과를 합치는 보팅부터 여러 결정트리를 병렬로 학습하는 배깅과 랜덤 포레스트를 살펴봤다. 이어서 이전 모델의 오류를 다음 모델이 보완하는 그래디언트 부스팅을 학습했다. 개별 모델과 앙상블의 성능뿐 아니라 학습 시간과 오류 패턴도 함께 비교했다.

### 사용한 함수

| 함수·클래스 | 역할 |
|---|---|
| `load_breast_cancer` | 유방암 분류 데이터셋 불러오기 |
| `read_csv` | CSV 파일을 DataFrame으로 읽기 |
| `train_test_split` | 학습용과 평가용 데이터 분리 |
| `GridSearchCV` | 파라미터 조합을 교차검증으로 탐색 |
| `LogisticRegression` | 확률 기반 선형 분류 모델 |
| `RandomForestClassifier` | 여러 무작위 트리를 결합한 분류 모델 |
| `GradientBoostingClassifier` | 오류를 순차 보정하는 부스팅 분류 모델 |
| `accuracy_score` | 분류 정확도 계산 |

## 실행 결과

앙상블의 효과는 모델 수보다 오류 패턴의 다양성에서 나온다. 비슷한 모델만 결합하면 계산량에 비해 개선이 작을 수 있다.

## 필요한 파일

유방암 및 Human Activity Recognition 분류 데이터

인체 활동 분류 부분에는 같은 DAY의 `data/human_activity_train.csv`, `data/human_activity_test.csv`가 필요하다. 현재 저장소에는 없다.

## 다시 볼 것

- 비슷한 모델만 모으면 예측 오류도 비슷해 앙상블 효과가 작다.
- 소프트 보팅은 각 모델의 확률값이 비교 가능한지 확인한다.
- 성능 향상과 함께 추론 시간, 메모리와 해석 난이도도 기록한다.
