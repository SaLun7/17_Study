# 11. 하이퍼파라미터 최적화

[← DAY3 목차](<README.md>) · [원본 노트북](<11_하이퍼파라미터 최적화.ipynb>)

Hyperopt의 탐색공간과 목적함수를 이해하고 XGBoost 파라미터 최적화에 적용한다.

## 핵심 개념

### 탐색공간

정수·연속·범주형 파라미터의 가능한 범위를 정의한다.

### 목적함수

파라미터를 받아 모델을 검증하고 최소화할 loss를 반환한다.

### TPE

이전 탐색 결과를 이용해 유망한 영역의 후보를 더 자주 선택한다.

탐색 알고리즘이 좋아도 잘못 정한 목적함수를 최적화하면 원하는 모델을 얻지 못한다. 불균형 분류라면 정확도보다 문제에 맞는 평가지표를 반환하는지 확인한다. 각 시도에 동일한 검증 방식과 난수 조건을 적용해야 파라미터 차이를 비교할 수 있다.

## 실습 흐름

조정할 파라미터의 범위와 평가 기준을 먼저 정한 뒤 여러 조합을 교차검증으로 비교했다. 탐색 과정에서 가장 좋은 조합과 점수를 확인하고, 선택된 설정으로 모델을 다시 학습해 별도 데이터에서 평가했다. 탐색 횟수를 늘리는 것보다 올바른 검증 구조와 범위를 정하는 일이 먼저라는 점을 확인했다.

### 사용한 함수

| 함수·클래스 | 역할 |
|---|---|
| `load_breast_cancer` | 유방암 분류 데이터셋 불러오기 |
| `train_test_split` | 학습용과 평가용 데이터 분리 |
| `cross_val_score` | 교차검증 점수 계산 |
| `XGBClassifier` | XGBoost 분류 모델 |
| `accuracy_score` | 분류 정확도 계산 |
| `confusion_matrix` | TN·FP·FN·TP 혼동행렬 계산 |
| `precision_score` | 정밀도 계산 |
| `recall_score` | 재현율 계산 |
| `f1_score` | 정밀도와 재현율의 조화평균 계산 |
| `roc_auc_score` | 확률 순위 기반 ROC-AUC 계산 |

## 필요한 파일

수학 목적함수 예제와 유방암 XGBoost 분류

데이터를 불러오는 셀부터 실행한다. 별도의 로컬 입력 파일을 지정하지 않는다.

## 다시 볼 것

- 테스트 데이터는 최종 조합을 선택하는 탐색 과정에 넣지 않는다.
- 파라미터 범위가 지나치게 넓거나 촘촘하면 시간만 크게 늘 수 있다.
- 최적 점수뿐 아니라 비슷한 성능을 내는 더 단순한 설정도 확인한다.
