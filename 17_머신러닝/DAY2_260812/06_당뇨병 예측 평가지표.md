# 06. 당뇨병 예측 평가지표

[← DAY2 목차](<README.md>) · [원본 노트북](<06_당뇨병 예측 평가지표.ipynb>)

피마 인디언 당뇨병 데이터의 비현실적인 0값을 보정하고 로지스틱 회귀의 임계값별 성능을 비교한다.

## 핵심 개념

### 의미 없는 0

혈당·혈압·BMI의 0은 실제 측정값보다 미측정값일 가능성이 높다.

### 표준화

서로 다른 단위의 피처를 비슷한 범위로 맞춰 선형 모델 학습을 안정화한다.

### 의료 임계값

질병 누락 비용이 크면 목표 재현율을 먼저 만족시키고 정밀도를 확인한다.

0을 결측으로 바꾸는 열을 잘못 고르면 임신 횟수처럼 실제 0일 수 있는 값까지 없애게 된다. 대체값과 표준화 기준은 학습 자료에서만 계산한 뒤 검증 자료에 적용해야 한다. 재현율을 올릴 때 거짓 양성도 늘 수 있으므로 두 종류의 오류를 함께 기록한다.

## 실습 흐름

당뇨병 데이터의 클래스 비율과 각 피처의 분포를 확인한 뒤 로지스틱 회귀로 기준 성능을 만들었다. 0으로 기록됐지만 실제로는 결측에 가까운 측정값을 점검하고 스케일링을 적용했다. 예측 확률의 임계값을 여러 값으로 바꾸며 정밀도, 재현율과 혼동행렬이 어떻게 달라지는지 비교했다.

### 사용한 함수

| 함수·클래스 | 역할 |
|---|---|
| `read_csv` | CSV 파일을 DataFrame으로 읽기 |
| `train_test_split` | 학습용과 평가용 데이터 분리 |
| `StandardScaler` | 평균 0, 표준편차 1로 표준화 |
| `Binarizer` | 지정 임계값으로 연속값을 0/1 변환 |
| `LogisticRegression` | 확률 기반 선형 분류 모델 |
| `accuracy_score` | 분류 정확도 계산 |
| `confusion_matrix` | TN·FP·FN·TP 혼동행렬 계산 |
| `precision_score` | 정밀도 계산 |
| `recall_score` | 재현율 계산 |
| `f1_score` | 정밀도와 재현율의 조화평균 계산 |
| `roc_auc_score` | 확률 순위 기반 ROC-AUC 계산 |

## 실행 결과

전처리 전후와 임계값별 지표를 같은 테스트 조건에서 비교해야 개선 원인을 설명할 수 있다. 평균 대체는 기준선이며 그룹별 또는 모델 기반 대체도 검토할 수 있다.

## 필요한 파일

Pima Indians Diabetes: Glucose, BloodPressure, BMI 등 건강 지표와 당뇨병 여부

같은 DAY의 `data/diabetes.csv`가 필요하며 현재 저장소에는 없다.

## 다시 볼 것

- 의학 측정값의 0이 실제 값인지 누락 표시인지 데이터 설명을 확인한다.
- 재현율을 높였을 때 늘어나는 false positive도 함께 계산한다.
- 최종 임계값과 전처리 기준은 별도의 검증 데이터로 정한다.
