# 05. 분류 모델 평가

[← DAY2 목차](<README.md>) · [원본 노트북](<05_분류 모델 평가.ipynb>)

정확도의 한계를 확인하고 혼동행렬, 정밀도, 재현율, F1, ROC 곡선과 AUC를 연결한다.

## 핵심 개념

### 정밀도

양성이라고 예측한 사례 중 실제 양성의 비율이다.

### 재현율

실제 양성 중 모델이 찾아낸 비율이다.

### 임계값

양성 판정 기준을 낮추면 일반적으로 재현율이 오르고 정밀도는 낮아진다.

### ROC-AUC

여러 임계값에서 양성과 음성의 순위를 구분하는 능력을 요약한다.

정밀도와 재현율 중 무엇을 우선할지는 잘못 분류했을 때의 비용에 달려 있다. 양성 확률을 출력하는 모델이라면 임계값을 바꾸며 두 지표가 함께 움직이는 모습을 보는 편이 단일 정확도보다 유용하다. ROC-AUC는 순위 성능이고 특정 임계값에서 실제 운영 성능을 대신하지는 않는다.

## 실습 흐름

한쪽 클래스만 예측하는 단순 모델을 이용해 정확도의 한계를 먼저 확인했다. 실제값과 예측값으로 혼동행렬을 만들고 정밀도, 재현율과 F1을 차례로 계산했다. 마지막에는 예측 확률의 임계값을 바꾸면서 두 지표가 어떻게 맞바뀌는지 보고 ROC 곡선과 AUC로 전체 구간을 비교했다.

### 사용한 함수

| 함수·클래스 | 역할 |
|---|---|
| `read_csv` | CSV 파일을 DataFrame으로 읽기 |
| `train_test_split` | 학습용과 평가용 데이터 분리 |
| `LabelEncoder` | 범주를 정수 라벨로 변환 |
| `Binarizer` | 지정 임계값으로 연속값을 0/1 변환 |
| `LogisticRegression` | 확률 기반 선형 분류 모델 |
| `accuracy_score` | 분류 정확도 계산 |
| `confusion_matrix` | TN·FP·FN·TP 혼동행렬 계산 |
| `precision_score` | 정밀도 계산 |
| `recall_score` | 재현율 계산 |
| `f1_score` | 정밀도와 재현율의 조화평균 계산 |
| `roc_auc_score` | 확률 순위 기반 ROC-AUC 계산 |

## 실행 결과

더미 분류기가 높은 정확도를 보여도 소수 양성을 하나도 찾지 못할 수 있다. 업무에서 FP와 FN 중 어떤 오류가 더 비싼지 먼저 정한 뒤 지표를 선택해야 한다.

## 필요한 파일

Titanic 및 digits 이진 분류 예제

같은 DAY의 `data/train.csv`가 필요하다. 타이타닉 데이터 파일이며 현재 저장소에는 없다.

## 다시 볼 것

- 양성 클래스를 무엇으로 정의했는지 지표를 보기 전에 확인한다.
- 정밀도와 재현율 중 어느 쪽을 우선할지는 오류 비용에 따라 달라진다.
- 임계값은 테스트 결과를 본 뒤 고르지 말고 검증 데이터에서 결정한다.
