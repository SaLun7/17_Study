## 핵심 메모

### 정밀도

양성이라고 예측한 사례 중 실제 양성의 비율이다.

### 재현율

실제 양성 중 모델이 찾아낸 비율이다.

### 임계값

양성 판정 기준을 낮추면 일반적으로 재현율이 오르고 정밀도는 낮아진다.

### ROC-AUC

여러 임계값에서 양성과 음성의 순위를 구분하는 능력을 요약한다.

## 결과 메모

더미 분류기가 높은 정확도를 보여도 소수 양성을 하나도 찾지 못할 수 있다. 업무에서 FP와 FN 중 어떤 오류가 더 비싼지 먼저 정한 뒤 지표를 선택해야 한다.

## 사용한 함수

| 함수·클래스 | 역할 |
|---|---|
| `read_csv` | CSV 파일을 DataFrame으로 읽기 |
| `train_test_split` | 학습용과 평가용 데이터 분리 |
| `LabelEncoder` | 범주를 정수 라벨로 변환 |
| `Binarizer` | 지정 임계값으로 연속값을 0/1 변환 |
| `LogisticRegression` | 확률 기반 선형 분류 모델 |
| `accuracy_score` | 분류 정확도 계산 |
| `confusion_matrix` | TN·FP·FN·TP 혼동행렬 계산 |
| `precision_score` | 정밀도 계산 |
| `recall_score` | 재현율 계산 |
| `f1_score` | 정밀도와 재현율의 조화평균 계산 |
| `roc_auc_score` | 확률 순위 기반 ROC-AUC 계산 |

## 정리

- 불균형 데이터에서 정확도만 사용하지 않는다.
- ROC-AUC에는 0/1 예측이 아니라 양성 확률을 사용한다.
- 임계값은 검증 데이터와 업무 비용을 바탕으로 결정한다.
