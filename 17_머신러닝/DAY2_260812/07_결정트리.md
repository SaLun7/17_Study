# 07. 결정트리

결정트리의 분할 규칙, 규제 파라미터, 특성 중요도를 확인하고 Human Activity 데이터에 GridSearchCV를 적용한다.

[← 과정 목차](<../README.md>) · [원본 노트북](<07_결정트리.ipynb>)

## 실습 내용

- 트리 구조와 불순도 감소를 이해한다.
- max_depth와 min_samples_leaf로 과적합을 제어한다.
- GridSearchCV로 검증 성능이 좋은 파라미터를 찾는다.
- 특성 중요도를 시각화한다.

**데이터**  
Iris, 합성 분류 데이터, Human Activity Recognition 데이터

## 핵심 메모

### 분할

한 질문으로 자식 노드의 불순도를 가장 크게 줄이는 피처와 기준을 선택한다.

### 과적합

깊은 트리는 학습 데이터를 잘 맞추지만 작은 변화에도 경계가 크게 흔들릴 수 있다.

### 특성 중요도

분할에 사용된 기여도이며 인과관계나 피처 방향을 직접 보여주지는 않는다.

```python
from sklearn.tree import DecisionTreeClassifier
from sklearn.datasets import load_iris
from sklearn.model_selection import train_test_split
import warnings
warnings.filterwarnings('ignore')

dt_clf = DecisionTreeClassifier(random_state=42)

iris_data = load_iris()
X_train , X_test , y_train , y_test = train_test_split(iris_data.data, iris_data.target,
                                                       test_size=0.2,  random_state=42)

dt_clf.fit(X_train , y_train);
```

```python
import numpy as np

def visualize_boundary(model, X, y):
    fig,ax = plt.subplots()
    
    ax.scatter(X[:, 0], X[:, 1], c=y, s=25, cmap='rainbow', edgecolor='k',
               clim=(y.min(), y.max()), zorder=3)
    ax.axis('tight')
    ax.axis('off')
    xlim_start , xlim_end = ax.get_xlim()
    ylim_start , ylim_end = ax.get_ylim()
    
    model.fit(X, y)

    xx, yy = np.meshgrid(np.linspace(xlim_start,xlim_end, num=200),np.linspace(ylim_start,ylim_end, num=200))
    Z = model.predict(np.c_[xx.ravel(), yy.ravel()]).reshape(xx.shape)
    
    n_classes = len(np.unique(y))
    contours = ax.contourf(xx, yy, Z, alpha=0.3,
                           levels=np.arange(n_classes + 1) - 0.5,
                           cmap='rainbow', clim=(y.min(), y.max()),
                           zorder=1)
```

## 사용한 함수

| 함수·클래스 | 역할 |
|---|---|
| `load_iris` | Iris 데이터셋 불러오기 |
| `read_csv` | CSV 파일을 DataFrame으로 읽기 |
| `train_test_split` | 학습용과 평가용 데이터 분리 |
| `GridSearchCV` | 파라미터 조합을 교차검증으로 탐색 |
| `DecisionTreeClassifier` | 결정트리 분류 모델 |
| `accuracy_score` | 분류 정확도 계산 |

## 정리

- 학습 정확도보다 교차검증과 테스트 성능을 본다.
- 중복 피처 이름과 데이터 타입을 모델링 전에 정리한다.
- 중요도는 permutation importance 등 다른 해석법과 함께 확인한다.
