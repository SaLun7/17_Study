# 07. 결정트리

[← DAY2 목차](<README.md>) · [원본 노트북](<07_결정트리.ipynb>)

결정트리의 분할 규칙, 규제 파라미터, 특성 중요도를 확인하고 Human Activity 데이터에 GridSearchCV를 적용한다.

## 핵심 개념

### 분할

한 질문으로 자식 노드의 불순도를 가장 크게 줄이는 피처와 기준을 선택한다.

### 과적합

깊은 트리는 학습 데이터를 잘 맞추지만 작은 변화에도 경계가 크게 흔들릴 수 있다.

### 특성 중요도

분할에 사용된 기여도이며 인과관계나 피처 방향을 직접 보여주지는 않는다.

트리의 첫 분할이 무엇인지 보면 모델이 데이터를 크게 어떻게 나누는지 읽을 수 있다. 다만 한 번의 분할에서 중요하게 쓰인 변수가 현실에서 원인이라는 뜻은 아니다. 깊이와 리프의 최소 샘플 수를 제한하며 학습·검증 점수 차이를 비교한다.

## 실습 흐름

결정트리를 기본 설정으로 학습한 뒤 트리 구조와 분기 기준을 시각화했다. 깊이와 최소 샘플 수를 제한해 복잡도를 바꾸고 훈련·테스트 성능 차이를 비교했다. 마지막에는 각 피처가 분기에 얼마나 사용됐는지 중요도를 확인하고 모델 해석의 단서로 활용했다.

### 사용한 함수

| 함수·클래스 | 역할 |
|---|---|
| `load_iris` | Iris 데이터셋 불러오기 |
| `read_csv` | CSV 파일을 DataFrame으로 읽기 |
| `train_test_split` | 학습용과 평가용 데이터 분리 |
| `GridSearchCV` | 파라미터 조합을 교차검증으로 탐색 |
| `DecisionTreeClassifier` | 결정트리 분류 모델 |
| `accuracy_score` | 분류 정확도 계산 |

## 실행 결과

규제가 없는 트리와 min_samples_leaf를 적용한 경계를 비교하면 지나치게 조각난 결정영역이 완화되는 것을 확인할 수 있다.

## 필요한 파일

Iris, 합성 분류 데이터, Human Activity Recognition 데이터

인체 활동 분류 부분에는 같은 DAY의 `data/human_activity_train.csv`, `data/human_activity_test.csv`가 필요하다. 현재 저장소에는 없다.

## 다시 볼 것

- 제한 없는 트리는 훈련 데이터를 지나치게 잘게 나눌 수 있다.
- 피처 중요도는 영향의 방향이나 인과관계를 뜻하지 않는다.
- 깊이, 잎의 최소 샘플 수와 교차검증 성능을 함께 비교한다.
