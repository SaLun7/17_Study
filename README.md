## 자료 보는 순서

과정 README에서 DAY를 고르고, 각 DAY의 표에서 학습노트와 원본 노트북을 연다. 개념과 저장된 결과는 `.md`, 실행 코드는 `.ipynb`에 정리했다. 큰 데이터와 모델은 필요한 경우 따로 준비하며, 위치와 포함 여부는 각 DAY 및 학습노트의 실행 메모에서 확인한다.
